## ① 增量（相对 10-09 复检）

1. **定位语升级为三动词叙事**："Prototype. Polish. Ship."——从"AI 生成原型"升级为**全生命周期**口径（原型→打磨→上线），首屏即 prompt 框+三个示例 pill（Onboarding flow/Data dashboard/Gradient gallery）。
2. **"Make Local" 出现**："Use Make locally to build in any codebase, then ship right to production. Coming soon."——**Figma Make 向本地代码库进军**（v0 repo sync/bolt GitHub 同向），生成平台集体打通"云端生成→本地代码"通道。
3. **控制权叙事**："Create anything. **Keep the control.** Start with design context, prompt, then edit on the canvas."——设计上下文先行+画布编辑；"control"一词进入平台卖点（第四层话语被平台借用，但仍无证据台账/强制门）。
4. **企业背书**：Ticketmaster PM 证言+"The products you love are designed in Figma"——企业级案例营销。
5. **三步 tab 叙事**：Design and ship / Build prototypes with context / Move fluidly between design and code——设计与代码双向流动成为独立卖点。

## ② 研判

- **平台四强（v0/bolt/Figma Make/Lovable）叙事已全部涉及"控制/验证/本地"**——第四层的"话语"全面被借用，但"证据"（分级+台账+强制门）仍无人做。第四层生存位收窄至证据纪律本身——**这恰是我们唯一不可替代物**，定位话语应全面转向"可验证交付"而非"门"（门已是平台词）。
- Make Local 与 v0 repo sync/bolt GitHub 汇聚成"生成→本地仓"通道——本仓"仓库即产物载体"路线获平台集体背书。

## ③ 可借鉴 / ④ 不抄

- 借鉴：①"Prototype. Polish. Ship."三动词节奏——门径叙事可缩为"解析. 契约. 交付"；②示例 pill（点即填 prompt）——画布产物墙可加"示例链路 pill"。
- 不抄：企业证言营销；cookie 弹窗合规形态无关。
