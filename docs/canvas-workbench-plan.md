## 二、三阶段路线（每阶段独立可交付，过门验收）

### 阶段 1 · 门径画布 MVP（数据→可视）

- **形态**：本地 React 单页（复用 showcase/products 的 Vite 管线与设计 token），读 `output/task-state.json`+`evals/results.json`+`docs/gates.md` 导出的 JSON。
- **画面**：①六道门时间轴（横向流水线，门状态 pending/approved/blocked 三色）②每门证据卡（截图缩略+链接+评分）③轮次日志流（iteration-log 尾部 N 条）。
- **交互**：点击门/节点展开证据抽屉；键盘可达；reduced-motion 降级。
- **数据更新**：`npm run canvas:build` 从文档/台账生成 JSON（静态生成，无后端）。
- **验收（门 E）**：画布自身过六维（桌面/移动/键盘/对比度实测/reduced-motion/console 零错）——吃自己的狗粮。

### 阶段 2 · 需求解析链路可视（黑盒→白盒）

- **画面**：门 A 解析卡结构化——`原始口语 → 需求摘要 → 范围边界 → 关键问题 → 参考素材（带来源链接）→ 设计契约摘要 → 产物 → 验收证据`，一条链路一屏，每步可展开"AI 当时看到了什么/依据什么决定"。
- **数据**：每轮产物在 `output/canvas/<轮次>/` 落一份 `chain.json`（schema 复用 task-state stages + 新增 `decisions[]`（每步的依据引用））。
- **审查可视**：每门审查记录（谁裁决/何时/依据/结论）入卡——**审查从文档态升级为界面态**。

### 阶段 3 · 品牌化高端壳 + 产物墙对比

- **品牌化**：画布自身按 design-contract 走一遍（语义 token/动效弹簧参数/暗色高端视觉）——**工作流的门面本身成为第 13 个案例**。
- **产物墙（流水线可视化）**：每轮开发线产出 1 个 mini 产物（mini-demo：单屏界面，2 小时粒度）入产物墙；**与对标产物并排**（v0/bolt/ instantaneous 同类截图，按六维并排打分）——学习循环新增 KPI4（产物级对比 ≥1/轮）。
- **产业化流水线**：mini 产物走完整六道门（Express 档），画布实时反映其在流水线中的位置——**流水线制从口号变为可视事实**。

### 阶段 4 · 工作台化与艺术画面（2026-10-19 用户裁定新增）

- **形态**：工作台从"画布页集合"升格为**产品门面**——持久化状态（task-state/chain/artifacts）+过程叙事（mission control/链路/产物墙/守卫回执）为一等公民；"持久化要使用"。
- **艺术画面**：视觉质量升级为明示验收口径（更好的界面/更好的艺术画面）——工作台自身按 design-contract 走品牌化（语义 token/弹簧动效/暗色高端），并与阶段 3 合并为"门面即案例"的持续线。
- **排期**：随增量滚动（当前增量 28/产物墙 3 条）；门径 tab 化（阶段→证据面板）为阶段 4 首个候选；验收仍走 canvas:check 三守卫（data/aria/导出对账）+六维直拍。
- **地平线衔接**：阶段 4 完成后按 identity 四序列进入"视频融合"（序列 3）——一切经受控编码路径，验收口径随形态定义。

## 三、测试样本扩量计划（并行线）

| 项 | 现状 | 目标 | 节奏 |
| --- | --- | --- | --- |
| evals 语料 | 73 条（71 执行） | 90+ | 每轮开发线新增 ≥2 条（优先 UI 专项：深色/3D/画布类/数据密集） |
| mini 产物 | 无固定 | 每轮 1 个 | 产物入墙+对比评分留档 |
| 对比基准 | 产品级对标（学习循环） | +产物级六维并排 | 随 mini 产物 |

## 四、门径与节奏

- 本文档=门 A 方向稿，**等用户裁决**（批准/修改/否决）。
- 批准后：阶段 1 预计 2-3 个开发线轮次出 MVP；阶段 2 再 2 轮；阶段 3 随产物墙积累滚动。
- 定时任务：开发线轮次的最高优先任务切换为画布工作台（经用户确认后更新轮次提示词）。

## 五、风险与边界

- 不做后端/账户/在线服务——画布是静态托管+本地构建（本仓"不是产品运行时"边界不变）。
- 产物对比的"网上效果"截图仅内部研究证据（ADR-0002 口径不变，不上 showcase）。
- 驱逐/降速环境风险：画布构建产物按 ignore 规则不入库，重建命令文档化。
