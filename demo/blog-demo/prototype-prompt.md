# 原型生图提示词（环节 4 · 路径 b）

> 背景：按 v5 思维链，原型环节「门F」要求使用 Stitch MCP 生成原型图。本环境
> 探测结果：`STITCH_API_KEY` 环境变量未设置、`.codex/config.toml` 中
> `[mcp_servers.stitch] enabled = false`、端点 `stitch.googleapis.com/mcp`
> 网络不可达（HTTP 000）。按门F 规则**不得虚构调用**，降级走 **路径 b**：
> 由执行代理输出一份可直接粘贴到 Stitch 网页版 / 任意生图工具的中文提示词，
> 用户自行生成原型图并回传，据此微调或进入契约环节。
>
> 使用方式：复制下方【提示词正文】到 Stitch 网页版 / 生图工具的输入框，生成
> 一张 **网页线稿风格的高保真原型图**；如工具支持指定尺寸，请生成
> **桌面 1440×900 与移动 375×812 两张**。

## 提示词正文（可直接粘贴）

```
请生成一个「个人博客展示页」的高保真网页原型图，编辑式、纸感、克制，
不是夸张的营销落地页。

【整体构图】
单页长图，自上而下依次排列六个区块，区块之间用 1px 浅色分隔线隔开：
1) 顶部导航：左侧品牌名「一舟札记」（衬线粗体），右侧三个文字链接
   文章 / 关于 / 订阅（「订阅」是描边圆角小胶囊按钮）；导航悬浮置顶，
   底色为半透明纸色，带轻微毛玻璃模糊。
2) 作者 Hero（左对齐编辑式排版）：左侧 88px 圆形头像（浅陶土底色上
   一个衬线大字「林」）；其下小号字距加宽的眉题「个人博客 · 写作与
   生活观察」；大标题「你好，我是林一舟。」（衬线、约 40px、近黑暖灰）；
   一段不超过两行的引文式介绍；下方两个按钮——实心主色按钮「阅读最新
   文章」与描边幽灵按钮「订阅更新」；再往下是三组极简元信息
   （已发布 36 篇 / 每月 1–2 篇 / RSS 可用），每组标签在上、数值在下。
3) 精选文章：眉题「精选文章」+ 衬线标题「最近写的」；下面 2 列 × 2 行
   的卡片网格，每张卡片是浅奶白表面、1px 浅描边、轻微投影；卡片内依次
   是日期与阅读时长（小号灰）、一个浅陶土底圆角标签（如「读书笔记」）、
   衬线文章标题、一行摘要、主色「阅读全文 →」文字按钮。
4) 关于：居中窄列（约 720px），眉题 + 衬线标题，三段介绍文字（正文小号、
   深灰、1.75 倍行高），下方一排圆角兴趣标签（写作 / 读书 / 城市漫游 /
   茶），最下一行两个主色文字链接（邮件 · RSS）。
5) 订阅：浅陶土色横条区块，居中窄列；衬线标题「每个月，一封信」+ 一行
   说明文字；白色圆角输入框 + 实心主色按钮「订阅」；输入框左侧有
   「邮箱地址」小标签。
6) 页脚：居中一行小号浅灰文字「© 2026 一舟札记 · 本页为个人博客展示
   Demo，内容为示例数据」，最右一个主色「回到顶部 ↑」链接。

【风格与色彩】
纸感中性底 #f7f5f0；卡片表面 #fffdf8；近黑暖灰主文字 #26221c，次文字
#57524a，分隔线 #e4ded1；唯一主色「锈陶」#a3411f 只用于按钮、链接、
标签、头像与焦点环，浅底变体 #f3e1d5。无图片、无插画，全靠版式与留白。

【字体】
中文衬线字体用于品牌、Hero 标题与文章标题（宋体风格）；中文无衬线
（苹方/思源黑体风格）用于导航、正文、按钮与表单。字号层次清晰：
40 / 28 / 22 / 17 / 15 / 13。

【动效意图】
hover 时：卡片上浮 2px 并加深投影、导航链接下划线从左向右生长、按钮
按压缩放至 0.98；进入视口时元素以 40–80ms 级联淡入上移；所有动效在
用户开启「减少动态效果」时完全静止。

【排版规范】
桌面 1440×900：Hero 约 920px 居中列，文章网格最大 1080px，区块上下
留白 64–80px。移动 375×812：全部改单列，导航收紧，按钮全宽堆叠。
整体要求：干净、安静、可读，像一份印刷纸质刊物，不出现玻璃拟态、
渐变彩虹或任何装饰性配图。
```

## 提示词调整记录（迭代信号）

- 若原型图与契约方向不符，调整顺序建议：先改「主色占比」→ 再改「衬线/
  无衬线比例」→ 最后改「区块顺序」。每次仅改一处并重新生成。
- 本环境无法执行生成调用，**未虚构任何 Stitch 成功记录**；原型图片本身
  同样未产出，需由用户在外部工具生成（见 ACCEPTANCE.md「未验证项」）。
