# Signal Deck · 需求信号板

回答一个问题：**AI 帮人写界面时，到底坏在哪一步**——把 4 份开发者问卷收敛成一条根因链、一张路线分叉图和四条已落地约束的洞察板。

[快速开始](#本地运行) · [数据边界](#数据边界) · [验证范围](#验证范围)

![Signal Deck 真实桌面截图：暖黑底琥珀主色，首屏三结论卡、根因链四步、环形图 2:1:1](evidence/desktop-1440.png)

> n=4 形成性参考，非统计样本。v1 曾被用户裁决不合格（灰单调/无真图表/未答解决什么问题），本版为重设计 v2。设计契约见 [DESIGN.md](DESIGN.md)，验收见 [ACCEPTANCE.md](ACCEPTANCE.md)。

## 能做什么

- 30 秒读懂：4/4 受访者全中、"确认派:举证派:混合 = 2:1:1"、改动半径纪律已入册——三个结论卡开场。
- 看根因链：局部需求 → **越权重写（坏在这）** → 偏离暴露 → 人肉修复，四步流向。
- 看路线分叉：SVG 环形图（弧长按周长精确对账）+ 两派原话并排，不用切换直接对比。
- 逐段溯证据：四段 C2 原话引语卡，每段带伤害类型标签（静默删除/7 文件/整页重写/结构混乱）。
- 看换回了什么：四条已落地约束（改动半径纪律×6/确认门话术/证据链加码/问卷 v2）。

## 数据边界

数据来源 = 研究仓 `formative/demand-survey-v1-responses.md`（4 份有效 + 1 份非目标样本不计入）。**n=4 是形成性参考，不是统计样本**——页面黄条显著标注，不做比例推断。引语为忠实转录不改写。无后端、无持久化、无外部服务；数据单口 `DATA` 常量内嵌。

## 本地运行

纯静态单文件：

```bash
cd demo/demand-insights
python3 -m http.server 4199 --bind 127.0.0.1
# 打开 http://127.0.0.1:4199/index.html
```

## 验证范围

v2 六维：1440 全页与 390 移动（零溢出、单列堆叠）亲验截图、对比度实测 11 对全过（4.5:1，含五强调色）、图配数一致断言（弧长=周长、2:1:1 三段）、reduced-motion 全静止、console 零错误——明细见 [ACCEPTANCE.md](ACCEPTANCE.md)。触屏真机与读屏全链路未测，如实标注。
