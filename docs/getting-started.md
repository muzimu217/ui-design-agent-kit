# 使用指南（Getting Started）

- 版本：v1 ｜ 2026-10-19 ｜ 对应产品：UI Design Agent Kit
- 一句话：**你出需求，工作流负责把它变成"有证据、可验收"的界面**——本 Kit 不做生成引擎，做的是生成过程的监管与质量把控。

## 一、你需要什么

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 运行环境 | Node.js 20+、npm | 用于跑校验与本地预览 |
| 宿主 | 任一支持 Agent Skills 的编辑器/CLI | Codex / Claude Code / Cursor / Copilot / Gemini CLI / Cline / Windsurf 等 13 个宿主 |
| 浏览器 | Chrome（用于实测验收） | 六维验收需要真实浏览器 |

## 二、三步开始

### 1. 安装

```bash
git clone https://github.com/muzimu217/ui-design-agent-kit.git
cd ui-design-agent-kit
npm ci --ignore-scripts
npm run verify && npm test
```

### 2. 告诉智能体你要做什么

在你的宿主里直接说人话，例如：

- "做一个深色数据看板，要有真实数据密度和清晰的层级"
- "把这个页面的对比度修到 4.5:1 以上，并给我实测回执"
- "给这个产品做一版官网首屏，走设计契约"

工作流会自动进入门 A（方向确认），**不会跳过确认直接产出**。

### 3. 看证据，不听说辞

每个产物都带六维实测（桌面/移动/键盘/对比度/降动效/控制台）。你可以随时：

```bash
npm run canvas:build    # 重建工作台（含产物墙与对比）
npm run canvas:check    # 跑实测验收（对比度/键盘/console + 三层守卫）
npm run canvas:export   # 导出离线复核包（含 COMPARE.md）
```

## 三、你会看到的四样东西

| 界面 | 作用 | 你能看到什么 |
| --- | --- | --- |
| **工作台入口** | 总览 | 方向与品味、能力接入、知识库、产物墙 |
| **门径画布** | 流程 | 六阶段 × 门态（谁在等谁裁决） |
| **解析链路** | 白盒 | 从你的原话到每个决定的依据 |
| **产物墙** | 证据 | 每条产物的六维实测、版本、来源、与对标并排 |

## 四、六道门是什么（为什么有时候会停下来）

| 门 | 停点 | 你要做什么 |
| --- | --- | --- |
| A | 方向确认 | 确认需求摘要与范围，避免做错方向 |
| B | 参考素材 | 确认参考来源（不抄外观，学机制） |
| C | 设计契约 | 确认 DESIGN.md（颜色/字体/间距/动效参数） |
| D | 修订 | 根据实测问题决定改什么 |
| E | 验收 | 看六维实测回执，决定是否通过 |
| F | 留痕 | 记录能力版本与证据路径，便于复现 |

**这些门不是流程装饰**：没有你的确认，工作流不会把"做完了"当成"做好了"。

## 五、能力接入（为什么有些能力是空的）

本 Kit 不内建生成能力。图像生成、3D 建模等外部能力必须通过 `docs/capability-adapters.md` 的**四问**（谁产出/边界/如何验收/证据在哪）才能用于交付。**空着的槽位是诚实状态**——没找到满足条件的候选就不接，不用未验收的能力给你交付。

## 六、常见问题

**Q：能不能直接给我一个完整网站，不要问我那么多？**
A：可以走 Express 档（简化门径），但门 E 的实测不能省——省掉的是"是否通过"的实测依据，不是流程。

**Q：我的偏好会被记录吗？**
A：会，但只记录**可复核信号**（你的原话、明确选择），不做心理画像；每条偏好都能回溯到具体信号，且你可以要求删除。见"品味档案"。

**Q：产出的东西能商用吗？**
A：代码归你；但第三方素材（图标/字体/图片）的许可证需要单独确认，见服务条款。

**Q：为什么有时候会拒绝执行？**
A：触发了边界（越权操作、未授权的外部服务、无法验证的宣称）。拒绝时会说明原因，不会静默跳过。

## 七、七原则自查（交给 AI 前/收货后的两分钟清单）

设计七原则（Balance/Unity/Contrast/Emphasis/Repetition/Pattern/Rhythm）是**审查词表，不是流水线**——单页通常只需同时满足 3-4 条。收货时问 AI 这四个问题：

1. **焦点唯一吗**（Emphasis）：这一屏最想让用户看的东西是哪一个？其他元素有没有让位？
2. **一致吗**（Unity）：色板/字族/圆角是不是各只有一两档？（AI 生成页最常翻车的是圆角五六个档位混用）
3. **读得完吗**（Contrast/Repetition）：正文与标题的区分够不够？重复出现的组件是不是长得一样？
4. **稳吗**（Balance）：左看右看重量分布有没有明显的"歪"？

> 这份清单是**提问词表**——用它们向 AI 提修改意见，比"感觉有点乱"有效得多。参数化定义见知识库 `design-seven-principles` 卡。
