# Video Craft（视频质感军规）

> 来源：2026-09-28 美感审计（intro.mp4 三处帧取证：致命因=无影像资产、
> 把 token 平涂+文字替代品当成品）+ 官方 Remotion 技能 + 通用实践。
> 服务视频专家分支；与 `remotion-video-agent`（编排流程与证据链）、
> `motion-contract`（动效数值）互补——本文件管"像不像影片"，不管"流程怎么走"。
> 适用阈值：≥15s 的对外视频全项适用；<15s 的内部 teaser 至少适用第 1、3 条。

## 1. 影像资产：录自家 demo，不做 token 平涂

- **规则**：brief 需要真实界面影像时，首选源=**录自家 demo**（浏览器实拍：
  桌面 1440×900 / 移动 375×812、60fps、按帧用途决定 reduced-motion 开关、
  光标路径预排）；已过门B 的素材蒙太奇次之。截屏序列经
  `<OffthreadVideo>`/`<Img>` 序列进组合，ffmpeg 抽帧对齐目标 fps。
- **禁止**：纯色底+文字冒充产品画面（审计致命因——替代品不是成品）；
  未过门的图库截图；把模板渲染画面声称成自家产品。
- 门B 提示：录屏是零授权风险源，不占素材预算；外部影像必须走门B 授权核查。

## 2. 镜头语言：推拉摇移的代码等价

- **规则**：≥15s 视频至少三种镜头变化——**推近**（scale 1→1.06 级缓动）、
  **摇移**（位置 X/Y 关键帧）、**遮罩转场**（clipPath 揭示）；场景纵深=
  前后景不同速率视差。转场落在 `Sequence` 边界，不用裸 fade 连续堆砌。
- 实现：`interpolate`/`useCurrentFrame` 组合——库驱动时间，几何自己算
  （与官方技能一致的帧数学纪律；预览即成品，乱序导出逐字节一致）。
- 反例（审计实况）：全片=spring 上浮+横扫两种动效，逐帧看像 PPT 切页。

## 3. 视频排版：display 级 + 安全区

- **规则**：视频文字用 display 级字族（非系统默认加粗）；字号层级 ≥2 跳；
  关键信息落安全区（画幅边缘 8% 内不放可读文字）；中西文混排显式声明字族。
- **对比度按帧实算**：帧会动——白字落在亮帧即翻车。取文字停留期的**锁定帧**
  抽验对比度（门E 先例：tagline/URL 帧检视把 2.3:1 修到 4.2:1）。

## 4. 声音：声明式处理，不虚构

- **要声音**：门B 找免版权源（YouTube Audio Library / Pixabay 类），授权
  记录入素材清单；kit 不生成音乐、不做配音合成。
- **无声设计**：brief 无声或交付环境静音时，编码显式静音 aac 轨（自动播放
  拒绝场景因此真实——批次三十五先例），并在视频契约写明"无声设计"。
- **禁止**：把"没声音"当默认不声明——声音状态是契约字段，不是缺席。

## 5. 叙事节奏：情绪顺序 ≠ 功能顺序

- **规则**：≥15s 视频须有结构设计——**钩子**（前 2 秒冲突/悬念，如
  "问题画面 vs 解决画面"对撞）→ **递进**（每段一个记忆点，段落不等权）
  → **收束**（数据定格/字标收尾）。信息顺序按情绪设计，不按功能清单铺排。
- 检验：逐帧过一遍，问"删掉这一秒观众损失什么"——答不出的秒数砍掉。

## 6. 工程起点与证据

- 从官方 Templates 最接近者 fork（许可核验后），不裸 Blank 自造；
- 帧数学全走 `useCurrentFrame` 纯函数；随机性必须种子化（乱序导出 md5
  一致性先例在案）；
- 证据链按 `remotion-video-agent` §证据：Studio URL / 渲染日志 / ffprobe
  全检（时长/分辨率/编解码/音轨）/ 代表帧五帧核对；**仅预览未渲染时不作
  成片声称**。
