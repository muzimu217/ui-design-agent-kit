## 是什么 / 不是什么（能力矩阵）

**是**：
- 一个项目级 UI 设计智能体：指令层（SKILL.md 体系 + 22 个技能）、有界工具编排（MCP 配置钉版）、六道门人工确认工作流
- 一套验证纪律：五级证据等级（Installed≠…≠VisuallyVerified）、116 项自动化测试（2026-10-04 全量口径：tests/ 107 + showcase/tests 9，计数由 doc-drift 锁定）、71 场景评测台账、浏览器实测强制
- 一个可迁移提示词工厂：`npm run prompt:build` 产出单文件提示词给其他宿主
- 12 个有独立 README/证据的线上案例

**不是**：
- 不是独立 AI 客户端/产品运行时（不提供模型服务、账户、付费素材）
- 不是运行时引擎/渲染框架（核心是智能体指令层+验证层，不假装有自动布局引擎）
- 不是 Figma 同步工具（设计源走 designContracts 品牌基线钉版通道，figma MCP 有意禁用）
- 不是 IDE 替代品（与 Cursor/v0 共存：本 kit 的价值在人机分工的确认门与证据纪律，不在生成能力本身）
- **不是研究项目本体**（research/ 是另一条研究架构线，见下）
