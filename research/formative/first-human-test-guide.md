# 首次人工测试指南：P1 形成性访谈试跑

> **给测试主持人的版本。** 这不是 C0/C1 受控实验，也不是 runner 测试；它验证的是研究问题、访谈提纲、录音/录屏、转写回传和编码入口是否能顺利工作。

## 你要测试什么

这次测试要验证三件事：

1. 受访者能否围绕最近一次 AI 做界面的真实经历讲出具体过程，而不是只给抽象评价。
2. 14 个主问题和追问能否在 45-60 分钟内完成，且不主动引导受访者制造“验证盲区”。
3. 录音、屏幕录制、匿名编号、转写和记录页能否形成一个完整回传包。

不要在本次会话中测试 C0/C1 条件差异、任务卡数字化、runner 门禁或评分者 κ；这些属于 P2/P3/P4。

## 测试对象与数量

- 第一次：先完成 1 场 `F-01`，用来验证流程是否可用。
- 正式 P1：累计至少 3 场，目标 3-5 场；至少包含 1 名 A 类前端和 1 名 B 类非专家构建者。
- 受访者不得参与过 UI Agent Kit 开发/内测，也不得进入后续实验池。
- 受访者必须在最近 3 个月有真实的 AI 做界面经历，并同意录音和屏幕录制。

## 场前

1. 从 [`recruitment-formative.md`](recruitment-formative.md) 使用描述卡和筛选问卷。
2. 通过筛选后只在研究记录中使用 `F-01`、`F-02` 等匿名编号；姓名、联系方式不要写入仓库。
3. 让受访者提前打开最近一次 AI 做界面的项目、对话记录或截图。
4. 准备会议录音和本地屏幕录制；确认录音和屏幕录制权限均已同意。
5. 打开 [`interview-protocol.md`](interview-protocol.md) 与 [`session-record-template.md`](session-record-template.md)。
6. 若对方不同意任一录制项，不开始本研究会话；不要用“口头记一下”替代已拒绝的录制许可。

## 开场话术

> “今天就是聊天，没有对错答案，你平时怎么用就怎么说，讲具体的事最好。我们会录音并录制屏幕，只用于研究、完全匿名；你随时可以要求删除。可以吗？如果可以，我们开始。”

得到明确同意后再开始录制。不要介绍我们自己的系统、假设或预期答案。

## 场中流程

按提纲自然对话，顺序可以调整，但主问题不能删除：

| 时间 | 内容 | 主持重点 |
| --- | --- | --- |
| 0-5 分钟 | 热身 Q1 | 确认角色和 AI 使用背景 |
| 5-25 分钟 | 最近一次经历 Q2-Q5、Q2b、Q5b | 追到具体项目、原话、时间和结果 |
| 25-39 分钟 | 验收习惯 Q6-Q7b | 先开放问，再按功能/视觉/交互/无障碍追问 |
| 39-49 分钟 | 失败故事 Q8-Q10 | 追问何时发现、浪费多少、谁判断完成 |
| 49-57 分钟 | 确认门反应 Q11-Q12 | 明确说这是设想，允许受访者嫌烦或拒绝 |
| 57-60 分钟 | 收尾 Q13-Q14 | 记录分层变量和可选材料 |

主持规则：

- 每个主问题尽量落到一个真实例子；抽象回答追问“能讲一次具体的吗？”。
- 不暗示“视觉/交互/无障碍一定会漏检”；让受访者先自己说。
- 不评价受访者过去做得对不对。
- Q12 的分钟锚点可以在超时时压缩，但最近一次经历 A 部分不可压缩。
- 出现计划外的重要话题，记录为“计划外”，不要为了赶表打断。

## 场后回传包

当天完成并回传以下内容：

```text
research/formative/
  F-01-transcript.md
  F-01-session-record.md
  F-01-audio.m4a       # 若平台导出格式不同，保留原扩展名
  F-01-screen.mp4      # 若平台导出格式不同，保留原扩展名
```

转写格式：

```markdown
# F-01 转写（日期 / 时长 / 受访者类型：A前端|B非专家）
[00:12] 我：……
[00:31] 对方：……
```

转写需保留口语，不要替受访者润色。记录页必须包含关键引语、时间点、初步失败模式和材料回收状态。真实身份信息放在受控的线下名单中，不放进仓库。

## 什么算一次有效测试

一场只有同时满足以下条件才算“有效 P1 会话”：

- 受访者符合筛选条件并使用匿名编号。
- 录音和屏幕录制同意已明确取得并记录。
- 转写覆盖完整会话，至少包含时间点和说话者。
- 记录页和转写能够互相对应。
- 没有主持人向受访者透露 H1-H4 或 C1 预期答案。

以下任一情况发生，记录为阻断项，不要把会话当作完整证据：录制未获同意、录音缺失、转写严重缺段、受访者不符合条件、身份信息误入仓库、主持人介绍了研究假设导致回答被引导。

## 首测结束后怎么反馈

请回传：

1. 完整回传包是否成功生成；
2. 哪个问题最难理解或最容易引导；
3. 哪个环节超时；
4. 是否出现提纲没有覆盖的重要主题；
5. 录音、录屏、转写和记录页是否能对应；
6. 你建议只改追问、还是需要暂停并修订主问题。

第一次测试的结果先记入 [`first-human-test-report-template.md`](first-human-test-report-template.md)。累计至少 3 份完整转写后，才进入 P1-5 编码和 P1-Gate 校准。
