## 2. 产品是什么（供你理解，不必照搬）

**一句话**：UI Design Agent Kit 是一个**专门为 UI 设计而设**的项目级 AI 智能体工作流——把"一句口语需求"变成"有证据的可验收界面"。

**它怎么干活**：整理需求 → 查找素材 → 确认设计 → 实现交互 → 浏览器验收。

**若你想讲立意**，核心区别在这里：生成赛道"更全"没有护城河（功能齐全的妙多 Motiff 已于 2026-07-31 停服）；它的稀缺位是**门（人工确认节点）+ 证据（可审计的验证链）**——六道门人工确认工作流 + 五级证据等级（Installed ≠ Configured ≠ Connected ≠ Invoked ≠ VisuallyVerified，"装了"不等于"跑通了"，更不等于"界面被亲眼看过了"）。

