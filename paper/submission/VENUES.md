# 计算机领域发论文与学术影响力路线图（VENUES.md）

> 接续 `SUBMIT.md`（自发布/预印本）——那份解决"先把论文挂到网上占坑"，
> 这份解决"真正提升学术影响力：往哪些 CS 会议/期刊投、怎么攒档案、怎么避坑"。
> 面向：单作者、本科院校、无机构邮箱、论文=自研开源项目的系统文档。
> 原则：**CS 领域的影响力 = 正式发表的会议/期刊论文 + 可核验的公开证据 + 互联的学术档案**，
> 三件事互相加成，缺一不可。

## 0. 一张图看懂：你的影响力阶梯

```text
第0步（已就绪）  预印本占坑      Zenodo/HAL/arXiv      → 时间戳 + DOI，防抄袭、可引用

随时             开源侧影响力     GitHub/知乎/社区        → 引用进来的读者变 star/合作者
```

**CS 领域和很多学科不同：会议 > 期刊。** 一篇 CHI/ICSE 论文的分量大于多数 SCI 期刊；
会议论文有正式论文集（ACM/IEEE 出版）、有 DOI、能被引——这和"发平台"完全不是一个层级。

## 1. 你问的"计算机领域的地方"：先认路标

### 1.1 CCF 推荐目录（中文世界的通用标尺）

中国计算机学会（CCF）把计算机领域认可的**国际会议/期刊分成 A / B / C 三档**，
保研、评奖、求职普遍认这个目录。查目录：

- 官方页：https://www.ccf.org.cn （"推荐国际学术会议和期刊目录"，最新版为准）
- 实用工具：**ccfddl**（https://ccfddl.com/）——按方向列出 CCF 会议的截稿日倒计时，找你方向最直观
- 备用聚合：https://www.wikicfp.com/cfp/ （全学科 Call For Papers 检索）

你的方向对应的板块：**人机交互（HCI）/ 软件工程（SE）/ 交叉的 AI4SE、LLM+UI**。
CCF 目录里相关会议举例（投稿前以当年目录为准）：CHI、UIST、IUI（HCI 档），
ICSE、ASE、FSE、ESEM（SE 档），以及大量 workshop。

### 1.2 会议的类型（本科生最该分清的）

| 类型 | 是什么 | 对你的意义 |
| --- | --- | --- |
| **主会**（full/short paper） | 正式论文，审稿 3 轮、竞争激烈 | 第 2–3 步再想 |
| **Workshop**（研讨会） | 主会周边的小型场，审 1 轮、 reception 好，正式出版进 ACM/IEEE 论文集 | **本科生友好入口，第 1 步首选** |
| **Poster / LBW / Demo** | 海报、Late-Breaking Work、现场演示，篇幅短（如 CHI LBW 4 页） | 门槛最低的"ACM 出版"形式，适合项目型工作 |
| **Journal** | 期刊，周期长（半年起），多数收 APC（版面费） | 见 §3 的费用提醒 |

### 1.3 预印本和会议不冲突（重要，很多人不知道）

CS 领域的惯例是**允许先挂 arXiv 再投会议**（绝大多数 CS 会议明确接受 arXiv preprint 投稿，
这和多数期刊相反）。所以正确顺序永远是：

```text
先预印本占坑 → 再投会议/期刊 → 录用后以会议版本为准（引用会聚到正式版）
```

`SUBMIT.md` 那套发布动作不会"用掉"这篇论文的新颖性。

## 2. 这篇论文（UAK）现在能投哪：诚实分级

先说实话：**这篇论文当前的证据强度（5 个执行场景、自评分、无基线对比）**
在 CCF-A/B 主会会被审稿人揪住。它现在最合适的出口是 workshop / LBW / demo；
想上主会，按 §4 补实验。分级如下：

### L1｜现在就可以投（和自发布并行）

| 去处 | 形式 | 为什么适合你 |
| --- | --- | --- |
| **CHI Late-Breaking Work**（CHI LBW） | 4 页短文 + 海报，ACM 出版，需至少一位作者注册参会 | HCI 最大会的低门槛入口，项目型工作常投；每年秋季截稿（查 ccfddl） |
| **IUI / UIST 的 companion（workshop/poster/demo）** | 短文或演示 | 你的主题（LLM 生成 UI + 人工门禁）正对 IUI/UIST 口味 |
| **ASE / ICSE / FSE 系的 AI4SE、LLM4SE 类 workshop** | 短文 | "agent 工作流 + 证据验证"在 SE 工具方向有现成 session |
| **国内会议/论坛的学生轨** | 中文/英文短文 | 留意 CCF 成都/北京等地分会、CCF 开源发展委员会活动；成本低 |

通用准备：把论文压到目标 CFP 的页数模板（ACM 主模板就是你现在这份 acmart，
workshop 通常同一模板改页数限制——这也是当初选 acmart 的原因）。

### L2｜小强化后投（1–2 个月的活）

| 去处 | 需要补什么 |
| --- | --- |
| **CCF-C 级会议**（SE/HCI 方向，查当年目录） | 执行 ≥15 个评测场景；找第二评分者做一致性；补 1–2 个"裸 prompt 基线"对照 |
| **EI 会议**（非 CCF 但正规；用 Think.Check.Submit 核验，见 §5） | 同上，标准略低；**当心混进去的水会** |
| **IEEE Access / MDPI（Electronics、Applied Sciences 等）** | 走期刊线，4–8 周出结果，但 **APC 版面费约 1,500–2,500 美元/瑞郎**——先想清楚钱包再投 |

### L3｜这就是下一篇论文的事

CCF-A/B 主会（CHI、UIST、ICSE、ASE……）需要的不只是修字：
多场景评测 + 双评分者一致性（inter-annotator agreement）+ 至少一个可比基线
（比如"同一批需求裸问一个强模型"）+ 理想情况一个 5–10 人的小用户研究。
这些正是你仓库里 `G2 回放协议 / G3 定时迭代` 规划要做的事——做完，论文自然升级。
**策略：这篇挂预印本/workshop 占坑，数据和实验攒够了写第二篇投主会。**

## 3. 学术影响力基础设施（发完论文 48 小时内做完）

影响力 = 有人**能搜到你、能引你、能找到你这个人**。四件套：

1. **ORCID**（orcid.org，5 分钟，要你实名操作）：学术身份证号。
   Zenodo/HAL/Preprints.org/SSRN 投稿时都绑它——保证所有平台的成果归到你名下。
2. **Google Scholar 档案**（scholar.google.com → 我的档案）：
   等第一篇 DOI 上线后再建（需要文章已被 Scholar 收录才能认领）。
   注意：用 qq.com 邮箱创建的档案可信度展示弱；如果你有学校邮箱（uestc 系），优先用它验证。
3. **Semantic Scholar**（semanticscholar.org）：不用注册，arXiv/Zenodo 上线后自动建页，去认领即可。
4. **开源侧互链**（我能做）：论文挂出去后，仓库 README 顶部加 "Paper: DOI / arXiv" 徽章、
   citation.cff 文件（让 GitHub 显示 "Cite this repository"）、仓库 release 触发 Zenodo 软件 DOI。
   ——论文给项目背书，项目给论文引流，这是你相对于"纯写论文的人"最大的优势。

## 4. 想冲更高级别：把证据做硬（下一篇的行动清单）

按性价比排序，都是你仓库现有机制的延伸：

1. **执行更多评测场景**：60 个场景脚本里抽 15–20 个真实执行（回放协议 G2 就是干这个的），
   记录通过率——把"5/5 全过"换成"20 个里过 17 个，失败 3 个的原因分析"。**有失败数据反而更可信。**
2. **第二评分者**：找一位同学/老师对同一批产物独立打分，报告一致率（kappa 或简单百分比）。
3. **一个基线**：同一批需求，不挂工作流直接问一个强模型，同一评分尺打分，报差值。
   哪怕基线也考得不错，"工作流在样式维度的增益（63→100）"依然是可讲的结论。
4. **小用户研究**：5–10 人用你的界面/流程，NASA-TLX 或 7 点量表问卷，报告均值和方差。

## 5. 避坑（比投稿更重要的一节）

- **掠夺性出版商**：特征=主动邮件邀稿、承诺 7 天录用、收高额 APC、目录外却自称"SCI"。
  投前过一遍 https://thinkchecksubmit.org/ 的检查单；中文圈再加一条：**不在 CCF 目录、
  也没有正规索引（EI/Scopus/DBLP）却要钱的，一律不投**。
- **"包录用""代写代发"**：全是诈骗或学术不端，出了问题挂的是你的名字；保研/留学背调一查一个准。
- **一稿多投**：预印本可以全网发（CS 惯例），但**正式投稿同一时间只能投一家**；
  会议在审稿期不能同时投另一会议（双投会被拉黑）。
- **作者身份**：永远如实——单作者就写单作者，AI 按 §5 披露（已在论文里）；别挂不存在的"合作者"。
- **APC 预算**：IEEE Access / MDPI 系一篇版面费折合人民币 **1 万–2 万**；
  workshop/main conf 注册费学生价通常 **几百–2000 元**。没钱就走 workshop + 预印本线，完全够用。

## 6. 怎么找到具体的截稿日（操作教程）

1. 打开 https://ccfddl.com/ → 左侧勾 Research Direction: `HCI/graphics` 和 `SE` →
   看倒计时列表，记下 3–6 个月内截稿的 workshop/conference。
2. 每个候选点进去读 CFP 页：确认主题清单覆盖 "LLM agents / design automation /
   human-AI interaction / developer tools"，确认**页数限制和模板**（大概率 ACM acmart，
   你现有论文改页数即可），记下投稿系统（通常是 OpenReview 或 HotCRP——都要注册账号，你亲手）。
3. 用 https://www.wikicfp.com/cfp/ 搜 "LLM UI" / "AI for software engineering" 补充非 CCF 场次。
4. 定 2–3 个目标（一主一备），按 CFP 倒排：内容冻结 → 内环自评 → 我出对应模板的 PDF → 你提交。
