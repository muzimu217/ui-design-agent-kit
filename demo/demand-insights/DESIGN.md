## 设计契约（falsifiable tokens）

- **语义 token**：`--bg #14100c / --surface #1e1812 / --raised #29211a / --ink / --ink-2 / --line` +
  五强调 `--amber #f5a623 / --cyan #3ecfd4 / --coral #ff6b5e / --mint #62d99a / --violet #b48cf2` 及各自 soft 底；
  组件区（token 块外）硬编码 hex **0 命中**、未定义 var 引用 **0 个**（node 脚本实测）。
- **Do**：数字 tabular-nums；首屏三卡渐变顶边区分语义色；图表 arc 长度与数值可对账；四态齐备；
  键盘可见焦点（amber outline）；reduced-motion 全静止（`* { animation:none!important; transition:none!important }`）。
- **Don't**：不虚构数据；不用纯颜色传达状态（图配文字+legend）；不做大面积单灰；
  不让弧长与数字不一致。
