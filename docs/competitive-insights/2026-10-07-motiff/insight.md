## 复检补拍新增事实（2026-10-11 实拍）

1. **官方时间线**（关停说明页表格）：2026-05-13 关停通知+关闭注册续费 → 2026-07-31 停服 → **2026-11-01 导出通道关闭，所有剩余数据永久删除**。通知到停服仅 ~2.5 个月；数据保留期仅 3 个月——**用户的设计资产终局是物理删除**，设计工具的"资产锁定"风险被现实演示。
2. **导出唯一出路=回 Figma**：批量导出全量打包为 Figma 格式——"从 Figma 迁来（图层/变量/组件完整保留）是卖点，回 Figma 去是终点"，生态位碾压的完整闭环。
3. **营销页定格现象**：官网仍以生前口吻完整运营（"产品设计，就用妙多 AI"、AI 席位 ¥90-300 定价表、博客矩阵），仅顶部一条红底停服横幅——**功能栈齐全的墓碑**。
4. **复检结论升级**：死亡复盘核心论断（"生存位不能是又一个生成工具，必须是门+证据+实验级可审计"）经实拍无变化且更硬；**首检 K2 立卡（该论述入 identity-and-direction）已于本轮落地**——用户 2026-10-11 原话"我们这个 UI 设计，是专门为 UI 设计而设的"解锁门 A，论述已入 identity v2 专用性锚定节。

## 它生前是什么（功能栈齐全得惊人）

风格学习导入→AI 生成界面/改版→**选中区域多版本"指哪改哪"**→组件/变体/变量完整保留→**妙多 MCP 让 AI Coding 工具生成高还原前端代码**。价格战阶梯（设计席位 ¥24 vs 企业 ¥90/150/300）。——把 v0/bolt/Lovable/Figma 的机制全部做过国产化，还率先做了"设计→代码"的 MCP 交付。

## 死亡信号（本轮核心知识）

1. **功能栈齐全 ≠ 生存**：与 Figma 正面克隆+AI 加持+本土价格战，仍被碾过——平台巨头的生态位碾压不认"你也很全"。
2. **对我们的警示与佐证**：我们的生存位**不能是"又一个生成工具"**（那条赛道尸横遍野），必须是门+证据+实验级可审计——这是五轮对标里唯一无人占据、且死亡名单反证稀缺性的位置。此论述应进 identity-and-direction 一句话定位（**K2 立卡：门开后随批落地**）。
3. **技术遗产**：妙多 MCP 证明"设计→代码经 MCP 交付"是可行通路——若未来对接任何存活设计工具，此通路可复用。
