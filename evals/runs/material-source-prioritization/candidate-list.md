> 不整合、不写实现代码。

## 〇、四类分类（先分家，不混装）

| 类别 | 本场景判定 |
| --- | --- |
| 页面/流程参考 | **需要**——表单 UX 与校验模式是预约产品的核心风险 |
| 组件 | **需要**——表单控件可直接复用成熟实现，降低自造轮成本 |
| 生产图片资产 | **不需要**——预约表单应零装饰图片（表单页视觉重心是输入效率）；如实写"零图片"而非硬塞 |
| prompt 素材（生成图参考） | **不需要**——无生成图需求 |

主搜索意图：**表单校验与错误提示模式**（预约产品最高频失败点=填写与提交，非装饰）。
首轮控制：1 个意图、3 个 primary、2 个 secondary，到此为止。

## 一、Primary（高分且可达 ✓，按多维排序非热度）

### 1. GOV.UK Design System — 表单模式与错误提示（页面/流程参考）
- 实查：patterns/ 与 components/text-input、components/error-message 均 **200**（2026-09-29）
- 授权：**OGL-3.0（政府开放许可，可改编需署名）**——清晰
- 改编成本：低（模式文档含错误消息写法与布局规则，非截图，规则可直译）
- 排序理由：任务相关性最高（表单校验=预约产品第一失败点）+ 规则可检查（文档即规格）

### 2. shadcn/ui — Form 组件（组件）
- 实查：docs/components/form **200**
- 授权：MIT；源码进仓库可直接检视——**可检查证据最强**
- 改编成本：低（React/TS 原生，token 接入既有契约即可）
- 排序理由：组件成熟度 + 源码可检 + 与目标技术栈一致

### 3. unDraw — 插图（生产图片资产，条件项）
- 实查：illustrations **200**
- 授权：开源许可（免费商用、可改色）——清晰
- 改编成本：低（SVG 可改主题色）；**仅当产品需要一张确认页插图时启用**——默认零图片
