# UI Design Agent Kit Showcase

UI Design Agent Kit 公开反馈仓库的发布资料。

**主产品是 UI 设计智能体工作流，demo 是工作流的成果案例。**

- [工作流与成果展示站](https://agent.kcos.club/)
- [参与测试](TESTING.md)
- [提交反馈或下一产品建议](https://github.com/muzimu217/ui-design-agent-showcase/issues/new/choose)

公开反馈仓库保存 issue 模板、测试说明和公开指引；展示站由 Agent 主仓库的
GitHub Actions 单独发布。此目录的 `SHOWCASE_README.md` 是反馈仓库 README
的同步源，不要向反馈仓库推送整个 Agent 工作树或构建目录。
依赖许可见 [THIRD_PARTY_LICENSES.txt](https://agent.kcos.club/THIRD_PARTY_LICENSES.txt)。

## 可体验案例

- [积木小工坊](https://agent.kcos.club/demos/brick-workshop/)：3D 拼搭、撤销、本机保存。
- [库存运营台](https://agent.kcos.club/demos/inventory-console/)：演示数据、搜索、筛选、排序、详情。
- [NODEGRID](https://agent.kcos.club/demos/nodegrid/)：地球、地图、节点搜索与详情。
- [地铁疾行](https://agent.kcos.club/demos/subway-runner/)：3D 跑酷、键盘与触屏操作。

其他标注为历史截图的案例不代表已经上线或全面验收。体验 demo 不等于运行了 Agent 工作流。
工作流源码已公开；执行时仍须使用有权访问的模型、服务和数据。

公开网站的文件校验清单位于
[build-manifest.json](https://agent.kcos.club/build-manifest.json)。此处没有用户数据服务、付费调用或自动私信邀请。
