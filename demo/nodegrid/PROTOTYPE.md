## 第二屏 · 全球网络地图（换场后的全屏舞台）

### 方向描述

点击地球触发 zoom-through 换场（~600ms，辉光过桥）后进入全屏：
**暗色科幻世界地图**（矢量底图 + 网格经纬 + 微弱地形等高线），
PoP 节点为**闪亮的像素光点**——核心节点大而亮（品白心 + 青晕 +
ping 脉冲环），边缘节点小而稳，规划中节点为虚线环；部分光点沿
光弧缓慢流动（流量可视化）。左上 HUD：图例 + 区域筛选 tab
（全部/亚太/北美/欧洲/特惠区）；右上搜索框。点击任一光点 →
右侧滑出节点详情面板。

### 路径 b · 生图提示词

```
全屏深色科幻世界地图界面设计图。近黑背景上的世界地图以电光青等高线

光点作为服务器节点：中心大城市的位置最亮（白心青晕 + 向外扩散的
脉冲环），次要节点是小的稳定亮点，另几个带虚线圆环表示"规划中"。
几条光弧连接各大洲节点，弧线上有流动的光点表示数据流量。左上角
HUD 风格图例与区域筛选标签，右上角搜索框，全部简体中文。
16:9 桌面视口，克制高级的 HUD 科幻感。
```

## 第三屏 · 节点详情 + 定价货架

### 方向描述

**节点详情面板**（点击光点滑出，右侧 380px）：顶部机房实拍图
（NASA 公有领域那张，裁切 16:10）；城市名 + 国家码 + 线路徽标
（CN2 直连 / BGP 多线 / CMI）；实时延迟大数字（等宽，ms）；
该节点可用产品与起价列表；实心青主按钮「部署到此节点」+
「相邻节点 →」跳转。

**定价区**（S4，紧随地图之下或退出地图后）：三货架 tab
（特惠区 / 普通区 / 全球节点）+ 产品卡片矩阵：轻量 ¥39 起（特惠角标
"限量"）、ECS ¥69/¥89/¥129 三区域卡、独立服务器 ¥399/¥899、
GPU ¥8.9/时；月付/年付切换（年付 -10%）；配置滑杆（vCPU/内存/带宽）
实时改价；卡角落统一「演示数据」水印级标注。

### 路径 b · 生图提示词

```
云服务器产品定价页设计图，深空科幻风。顶部三个货架标签：特惠区 /
```
