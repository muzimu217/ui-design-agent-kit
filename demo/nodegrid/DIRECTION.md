## 视觉基调（v2 修订：科技科幻）

**深空科幻 × 全息霓虹**：near-black 深空底（#04070D 量级）+ 电光青主色、
品红/紫外点缀；数据全等宽字体（tabular-nums）；全息线框、HUD 角标、
扫描网格地台、克制的辉光。世界地图节点是**闪亮的像素光点**，可沿光弧
流动移动；其余界面收敛为干净的企业科幻暗色，不堆玻璃拟态。

## Logo 规格（附件 logo-demo.html v4，纯 CSS）

> 演进：v2（14 体素平板，方向认可但太简陋）→ v3（挤出柱地形云，
> **存在几何缺陷被用户门A 抓出**：侧裙以原点居中而非贴合柱体，顶面与
> 侧裙间空半格 → "顶面悬浮 / 散点像素面"）→ v4（回到像素格子本体）。

- 形态：**像素格子云**——88 个完整立方体格子（每格顶 + 四侧 5 面，
  面片全部贴合体素中心，任意角度实心不散架），三层堆叠：
  底层 12×7 大云形 52 格 + 中层 28 格 + 顶层 8 格；
- 工艺：CSS 3D transforms；**亮度按层分档**（顶面 hsl 亮度 52/62/72%
  三台阶）+ 四向 AO 暗面梯度 + 随层增亮的 1px 霓虹描边；辉光由独立
  .halo 光斑层承担（替代逐帧重算的 filter drop-shadow，面数多时更稳）；
- 细节：数据雨滴（云底坠落发光像素）；HUD 刻度环地台（虚线环 + conic
  刻度环反向慢转 + 地面光晕）；wordmark + 副标；
- 交互：默认 20s 缓慢自转；点击（checkbox hack，零 JS）切换轮转展示：
  双轴环绕 + 加速自转 + 双扫光 + halo 放大 1.22 + 雨滴加速；
  hover ≤150ms 微倾；reduced-motion 降级静态（隐藏雨滴）。
- 视觉验证留痕（2026-09-07 v4）：结构断言 88 格 / 440 面 / 0 个畸形格；
  **近平视角（rotateX 10°，最易暴露悬浮面的角度）专项核查通过**——
  无悬浮面、顶面与墙面无缝贴合、三层连续成体；双态截图核验 + 点击
  断言（checked 翻转、fast-spin/orbit-tilt、halo matrix scale 1.22）；
  v3 缺陷已消除。**v4 已获用户认可（"可以的"，门A logo 3D 定稿）。**

## 动效意图（motion-contract 家族）

入场：地球淡入 + 节点级联点亮 stagger 40-80ms；logo 16s 自转；
换场：hover/press ≤150ms，zoom-through ~600ms 减速曲线 + 一步辉光过桥；
节点：ping 脉冲环 + 光点沿弧线流动；reduced-motion 全站降级静态。
