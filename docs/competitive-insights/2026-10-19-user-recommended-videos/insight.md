## 二、开源仓库深读：`liyupi/ai-promo-video-maker`（本轮核心）

## 三、六条视频的判读

1. **Opus 5.5 视频生态已成规模**（7.8 万/3.3 万播放的教程，1000+ 提示词仓库，15 种商业风格，1080p60 横竖屏）——**"提示词直出视频"是当前最热的能力形态**，但它本质是"模型写代码渲染"，与本仓 remotion 路径同源。
2. **技术栈科普已存在**（"Opus 5.5 是怎么用代码做视频的：从画面、声音到 MP4"）——说明"代码做视频"已进入大众认知，**我们的叙事不需要解释"为什么用代码"，而要解释"为什么需要监管"**。
3. **3D 路径 = 通用大模型 + 专业工具（Meshy）**——正是我们"能力外接"的范式，可直接作为 `3d-modeling-pending` 槽位的候选。
4. **Frameronin（像素序列/多向动作）**——用户判断可作素材模块。它属于"素材生成能力"，按契约应登记为 `evaluating` 候选，用途=游戏/像素风项目的素材源。
5. **模型横评（5 个角度）**——用户要求"研究模型适合的角度"。这条给出方法论：**按维度横评**（而非总分），与本仓 KPI4 六维并排同构。
6. **网站滚动效果教程**（卡尔的AI沃茨）——直接对应本仓"艺术画面"方向，滚动叙事是可编码的（ScrollTrigger 已在库内）。

## 六、Edge 浏览器（用户要求）

- **现状**：Edge 已安装且在运行（PID 3084），但**未开远程调试端口**；`chrome-devtools` MCP 是 stdio 模式自起 Chrome，无法连到已运行的 Edge。
- **可行方案**（需用户一句话确认，因为会短暂关闭当前 Edge 窗口）：
  ```bash
  # 1) 退出 Edge
  osascript -e 'quit app "Microsoft Edge"'
  # 2) 用你的默认配置 + 调试端口重启（Cookie/登录态保留）
  "/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge" --remote-debugging-port=9222
  # 3) 之后我可用 CDP 连到 9222，复用你的 B 站登录态
  ```
