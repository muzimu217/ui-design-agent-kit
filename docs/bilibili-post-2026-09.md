## 简介区文案

AI 编码代理写代码很快，但生成的界面经常"一眼假"：配色脏、排版乱、细节没人管。

这个开源项目（UI Design Agent Kit）给 AI 代理装了一套 UI 验收体系：
・6 道门禁：设计稿→素材→原型→实现契约→验收→证据留痕（与 docs/chain-flow.md §五一致）
・71 个评测场景 + 评分台账：分数不是自评，每条都有浏览器实测背书
・今天刚达成的硬指标：线上 20 个页面×明暗双主题，无障碍扫描 0 违规（serious/critical 全清）
・附论文与 DOI，方法可复现

GitHub 仓库见置顶评论（Apache-2.0 开源，Claude Code / Codex 等 Agent 均可装）。
概念演示页，数据为示意；非恰饭，个人开源项目。
