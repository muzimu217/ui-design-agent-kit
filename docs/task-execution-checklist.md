## 0. 使用规则

### 0.1 每个任务的执行回报必须包含

- [ ] 任务编号和任务名称
- [ ] 实际修改的文件
- [ ] 没有修改但检查过的文件
- [ ] 完成了哪些子项
- [ ] 使用了哪些命令或工具

- [ ] 未完成项、阻塞项和需要用户裁决的事项
- [ ] 是否满足本任务的验收条件

### 0.2 通用停止条件

遇到以下任一情况，停止当前任务并如实回报，不自行扩展范围：

- [ ] 需要用户决定研究规模、任务卡、评分标准或伦理材料
- [ ] 需要修改另一个仓库
- [ ] 需要提交、推送、合并、创建 PR 或发布
- [ ] 需要购买服务、升级套餐或登录第三方服务
- [ ] 需要上传版权或来源不明确的素材
- [ ] 需要删除或改写既有评测证据
- [ ] 测试失败但无法在当前任务范围内解释和修复
- [ ] Mimosa 或其他安全钩子拦截操作
- [ ] 发现现有用户修改与任务目标冲突

### 0.3 Git 边界

- [ ] 开发线只在 `ui-design-agent-kit` 的 `dev/auto` 分支工作
- [ ] 开发线不直接提交或推送 `main`
- [ ] 研究线只在 `uak-research` 工作
- [ ] 研究线不修改开发线仓库
- [ ] 任何 commit、push、PR、merge、rebase、tag 等外发操作，必须先获得用户针对该具体操作的口头放行
- [ ] 不使用改写命令、删除证据或换工具规避安全钩子
