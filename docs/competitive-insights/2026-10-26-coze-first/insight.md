## 机制观察

1. **定位巨变**："字节跳动旗下**职场 AI 伙伴**+一站式 AI 开发平台"——从 Bot 开发平台升级为职场代跑：H1 "工作交给扣子，创造不必等待""Agent 会带着资料和工具接手，把想法一步步做出来"。
2. **规模信任锚之最**："已有 **100,512,213 个 Agent 正在工作**"——用 agent 在岗数量级做信任（对照 bolt 20 家企业墙/MasterGo 100+ 头部企业/claude-mem 103k 星——四种信任锚形态：企业墙/头部数/星数/agent 数）。
3. **"招募你的 AI 同事"人格化组织叙事**：AI 作为团队编制入职（与 Base44"works while you sleep"、MasterGo"先跑为敬"同族但更彻底——直接叫同事）。
4. **执行边界扩展到真机**："授权 Agent 使用你的电脑，为它分配云端服务器，再配一台专属云手机。文件、代码、网页和 App，都能成为它真正工作的地方"——桌面端+云端服务器+云手机三层执行位。
5. 多模型组合明示："支持多种顶尖模型与领先的 Agent Harness"——演示对话里出现 GLM Agent 字样（多模型接入的平台型姿态）。
6. "成果已交付""方案评审已经完成，关键风险和补充建议均已标出"——演示对话自演交付与评审——**评审被演出但无一处可复核回执**。
7. 第四层连续 38 轮无存活对标者（演出式交付是最远形态：连"宣称测量"都没有，直接演结果）。

## 判读

1. **代跑光谱的两极闭合**：Coze（全权接手+真机执行+AI 同事编制）↔ kit（AI 跑之前先对齐+门控停点+证据回执）——问卷 C2 痛点（越权代跑）的供给侧最大样本出现，痛点-方案两极同时成型。
2. **信任锚形态学**：企业墙（ bolt/MasterGo）→星数（claude-mem）→agent 在岗数（Coze）——规模叙事从"谁在用"进化到"多少个 AI 在干活"；kit 不用规模锚，用可复核回执锚（第三种锚：证据锚）。
3. "授权 Agent 使用你的电脑"是执行边界的重大让渡——用户交出真机控制权换效率；kit 的边界观（AI 在沙箱/项目目录内工作、产物过门）与此构成执行层对照。

## 不抄什么

"1 亿 Agent 在工作"规模叙事；"AI 同事"人格化话术；演出式交付演示。
