## 机制观察

1. **策展站的引用结构**：recent.design 的 Motion 作品**全部外链到作者的 X 帖**（而非独立网站）——动效作品的"可展示单元"是 X 帖内的短视频，策展站只做聚合。**这与 Interface 类（作品多有独立站点）形成对照：纯动效作品的发布位=X**。
2. **对本仓的访达影响**：X 需登录（IAB 不走代理）→ **Motion 类作品深访持续受阻**——不是站点不可达，是**作品源平台不可达**。此为第 3 次因 X 依赖受阻（70 轮改道、本轮再确认）。
3. **行动含义**：Motion 素材的研究路径应改为**B 站/YouTube 的动效内容**（可达），X 作为"发现渠道"记录但不作为研究入口。

## 判读与转化

1. **改道决定（结构性，非一次性）**：Motion 类研究入口从 recent.design 改为 B 站动效区——64 轮预告的"图标动效系统"深访**顺延至 B 站路径**，本轮如实记录受阻。
2. **本轮转产**：深访不可达 → 本轮把 64 轮立卡的"七原则自查节"落地（getting-started/DESIGN.md 文档转化，L4），保持轮次产出。
