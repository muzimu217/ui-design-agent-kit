# UI Design Agent Kit Showcase

UI Design Agent Kit 的公开成果展示与测试入口。

**主产品是 UI 设计智能体工作流，demo 是工作流的成果案例。**

- [工作流与成果展示站](https://muzimu217.github.io/ui-design-agent-kit/)
- [参与测试](TESTING.md)
- [提交反馈或下一产品建议](https://github.com/muzimu217/ui-design-agent-showcase/issues/new/choose)

这个仓库只保存可公开的编译产物、精选截图、依赖许可和测试说明。它不包含私有 Agent 指令、
原始应用源码、MCP 凭证或内部评测资料，也没有为整个项目重新声明开源许可证。
依赖许可见 [THIRD_PARTY_LICENSES.txt](docs/THIRD_PARTY_LICENSES.txt)。

## 可体验案例

- [积木小工坊](https://muzimu217.github.io/ui-design-agent-kit/demos/brick-workshop/)：3D 拼搭、撤销、本机保存。
- [库存运营台](https://muzimu217.github.io/ui-design-agent-kit/demos/inventory-console/)：演示数据、搜索、筛选、排序、详情。

其他标注为历史截图的案例不代表已经上线或全面验收。体验 demo 不等于运行了 Agent 工作流。
工作流执行评测面向已获得维护者访问授权的测试者；不会因为提交反馈而自动获得私有仓库权限。

公开网站来自 `docs/`，由 GitHub Pages 发布。每次版本的文件校验清单位于
`docs/build-manifest.json`。此处没有用户数据服务、付费调用或自动私信邀请。
