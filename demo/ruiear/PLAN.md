- **任务类型**：产品营销落地页（campaign/experience 面），M 级→升 L 级链路（双语 i18n + 自有视觉体系 + 3D 叙事，跨多区块的品牌定义工作）。
- **原始需求**：睿耳（睿数旗下）AI 耳机产品落地页；Apple 极简打底，叠加用户自有风格（分区色彩身份、同心色环过渡、大幅动效）；产品多配色；三档价格。
- **已确认决策**：
  - 入耳式 TWS；概念页（无真实产品图，demo 标注）；
  - Vite + React 单页项目；
  - 3D 底模：**A1 Tripo 白模（用户已选定）**，GLB 由用户后续下载提供；降级方案=程序化建模（R3F 几何拼装，授权最干净）；
  - 品牌：**睿数**（母品牌）/ **睿耳**（产品品牌，英文占位 RuiEar）；
  - 配色 5 款：**月光白 / 午夜黑 / 天空蓝 / 落日橙 / 玫瑰红**（HEX 原型门定）；
  - 双语：**中文 / English 可切换**（导航语言开关 + 全站文案字典）；
  - 流程：**原型先行**。
- **使用者与场景**：浏览产品页的潜在顾客；桌面 + 移动浏览器；中英两类用户。
- **首版必须完成**：见下方结构 1–8 全部区块；3D 开合盖/入仓动画；中英切换；三档价格卡。

## 视觉方向（Apple 打底 + 自有风格）

- 基线：Apple AirPods 产品页（R1/R2 实拍证据）；超大紧排标题、大留白、克排版式。
- 自有风格层（用户 2026-09-12 拍板）：
  - **色调旅程**：顶部区块鲜艳饱和 → 往下渐趋平淡素净；每区块一个主题色身份；
  - **同心色环过渡**（签名交互三）：跨板块时出现过渡界面，背景一圈圈色环扩散后揭示新区块；
  - **明暗区块过渡动效**：深/浅色区块切换带联动动画；
  - **动效幅度放大**（用户明确要求），保持 Apple 式高级感，spring 驱动。
- 组件来源（T-003 素材拼接优先）：色环/涟漪过渡先查 Magic UI、React Bits 现成组件（per-component 许可逐一核），无适配则本地实现并记录理由。
- 动效：Motion spring（Elegant 为基，重点区块允许更大幅度）；`prefers-reduced-motion` 全部退化为立即态/淡入。
