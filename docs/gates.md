## 二、登记与衰减规则

- **登记**：任何产物停门前，主代理追加一行（门 / 事项 / 证据位置 / 首次
  提出日期 / 轮空计数 / 状态）。裁决后回填"裁决结果 + 日期"，**不删除行**。
- **状态**：`open`（待裁决）→ `approved` / `declined`（用户裁决）/
  `auto-declined`（衰减，附日期与理由）。
- **轮空计数**：每个"裁决窗口"（一次用户交互会话，或一轮迭代冲刺）结束
  时，仍为 `open` 的事项轮空 +1。
- **P2 衰减（提案基线，待定责 D1）**：门E 的 P2 级事项连续 **2** 个窗口
  无人勾选 → `auto-declined` 并留痕；**门A/门B/门C 的方向类事项不自动
  衰减**，只能由用户裁决——自动轮与衰减规则都不得代替用户过方向门。
- **批量裁决**：`open` 累积 ≥8 项（提案阈值，待定责 D2）或用户发起时，
  主代理整理一页纸清单（事项 + 证据位置 + 一句话建议）请用户逐项定夺。
- **权威性**：门账本为门上事项唯一权威记录；sprint 总结与 iteration-log
  引用不重复登记。
