# 曜石 12 Pro

比较两款虚构手机、选择容量与颜色、整理购买意向的交互演示页面。

> 预约或支付，也不连接任何后端服务。本项目与历史截图中同名「曜石 X1」项目无关。

> **许可**：目录未授予开源许可（`package.json` 无 license 字段、仓库为内部许可）。

## 功能与交互

- **机型比较**：Pro 与 Pro Max 并排比较演示规格。
- **容量选择**：256GB / 512GB / 1TB 三档，联动演示价格（非真实售价）。
- **配色选择**：曜石黑、霜白银、翡翠绿，切换后当前配置实时更新。
- **意向清单**：把配置加入本页清单（仅存于当前页面会话，不做持久化）。
- **常见问题**：页内锚点浏览。

交互以鼠标与键盘双路径实现：选择器为原生控件、可 Tab 到达，价格与配置更新
对读屏以文本形式可见。

## 快速开始

需要 Node.js ≥ 24（见 `package.json` 的 `engines`）。在**仓库根目录**执行：

```bash
cd demo/phone-demo
npm ci --ignore-scripts
npm run dev -- --host 127.0.0.1 --port 5181
```

打开终端显示的地址（探测用 `localhost`）；端口冲突时换端口即可。

### 构建与检查

```bash
npm run build        # tsc --noEmit 类型检查 + vite 产物构建
npm run preview      # 本地预览构建产物
```

依赖以 `package-lock.json` 为准，重装请用 `npm ci` 而非 `npm install`。

## 数据边界

- 页面内所有商品、规格、价格均为**演示数据**，硬编码于前端，无 API、无账户、
  无持久化——刷新后意向清单即清空。
- 「曜石 12 Pro」为虚构品牌设定，页面中的机型渲染图为页面绘制，不是实物照片。

## 验证范围（诚实声明）

- **有**：TypeScript 类型检查（`build` 内含 `tsc --noEmit`）、生产构建、
  浏览器桌面/窄屏走查（见 `ACCEPTANCE.md`）。
- **无**：`package.json` 没有 test 脚本，本项目当前没有自动化测试——
  不要按"跑过测试"理解本页；构建成功 ≠ 全面验收。

## 已知局限

- 意向清单无持久化（刷新即失），属当前版本的边界而非缺陷。
- 移动端为响应式适配，未做原生 App 形态。
- 深浅色跟随系统，无独立主题开关。
