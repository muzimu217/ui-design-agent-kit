03

同心色环过渡（签名交互三 · 分镜）

跨板块触发：新板块主题色从屏幕中心一圈圈扩散成满屏色场，随后内容在新底色上揭示。动效幅度大（你的要求），spring 驱动，约 700–900ms，滚动反向可回退；reduced-motion 退化为直接淡入。

帧 1 · 滚动接近边界，页面静止
帧 2 · 主题色环从中心扩散（实心+描边环）
帧 3 · 满屏新主题色场（短暂占位）
新板块内容揭示
帧 4 · 内容在新底色上淡入，色场退为区块底色

实现路径（T-003 素材拼接优先）：先检索 Magic UI / React Bits 的 ripple / concentric 现成组件并核许可；无适配则本地 CSS/SVG 实现，理由入契约。
