# ADR-0002：竞品截图仅本地留存不入库

- 状态：已接受 ｜ 日期：2026-10-08（用户确认） ｜ 源规则：docs/learn-loop.md 证据纪律

## 背景

对标学习循环产出竞品截图（浏览器实拍）。本仓是公开仓，把第三方产品截图提交进 git
等于对外发布，与"版权克制、不上 showcase 不外发"纪律冲突；但截图留在工作区又面临
换机器丢失、本人无法集中浏览的问题。

## 决策

1. 竞品截图**只存本地**工作区（`docs/competitive-insights/<日期>-<对象>/*.png`），
   不提交进公开仓，不进入研究仓（两仓分离）。
2. 知识卡 `insight.md`（自产文字）正常入库，内文引用截图文件名并注明"本地留存"。
3. 本地浏览页 `docs/competitive-insights/viewer.html` 由
   `scripts/competitive-insights-viewer.mjs` 扫描目录生成，列入 `.gitignore`，
   供用户本机集中查看各家产品现状；生成器脚本入库，生成物不入库。

## 理由

- 版权克制：截图仅作内部研究证据；
- 文字知识卡已满足"证据可复核"的公共部分（机制描述、来源 URL、检视级别）；
- 本地 viewer 解决用户侧的集中浏览需求，不产生对外发布。

## 后果

- 公开仓中知识卡引用的截图在 GitHub 上不可见（预期行为，卡内已标注）；
- 换机器时截图不随 git 迁移，依赖本机备份区（~/Documents/Projects 已在夸克备份范围）；
- 每轮新增截图后需重跑生成器刷新 viewer。
