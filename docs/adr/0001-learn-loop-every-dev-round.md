# ADR-0001：开发线每轮必做对标学习循环

- 状态：已接受 ｜ 日期：2026-10-07（用户裁定） ｜ 落地记录：2026-10-08

## 背景

开发线无人值守轮此前以"健康探测+压仓"为主，产出容易空转；用户要求每轮向市场学真东西。

## 决策

开发线每一轮（无人值守与交互一致）必须完成一轮对标学习循环，规范见
[docs/learn-loop.md](../learn-loop.md)：选对象（池内轮换不重复）→ 浏览器实看截图取证 →
知识卡入 iteration-log → 落地一个优化或立卡说明暂缓原因。三 KPI（知识卡/优化/证据）
缺一即轮次不合格。

## 理由

- 对标学习把"维护"轮变成"学习-研究-开发-验证-对照-反馈"的增益轮；
- 截图证据 + 对照表防止凭记忆和搜索摘要充当"看过"；
- K2 强制"落地或说明暂缓理由"，防止"为改而改"。

## 后果

- 对象池需要持续扩充（第一 sweep 9 项已于 2026-10-08 完成首轮检视，第二 sweep 候选已入池）；
- 竞品洞察目录 `docs/competitive-insights/` 持续增长，文字入库、截图本地（见 ADR-0002）；
- 每轮收尾成本增加约 20-30 分钟，换取可复核的市场认知积累。
