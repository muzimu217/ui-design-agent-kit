## 机制观察（①学习 ②研究）

1. **首屏彻底改版为 prompt 入口**：「Pixso **智能设计**——创意由你定义，AI 让设计加速」；首屏主体=大 prompt 框（placeholder"描述你想设计的页面，包括用户、主要功能和风格"）——10-08 首检时首屏还是工具功能陈列，现在与 Figma Make/v0/Wegic **同一 prompt-first 入口范式**，国产"生成前置型"定位落地到首屏。
2. **设计系统作为生成"附件"（本轮最独特机制）**：prompt 框内置 **「智能设计系统」按钮**，tooltip 明示"前往工作台后即可选择图片上传、**选择设计系统附件**"——设计系统不是全局设置（v0 DS 2.0 口径）而是**随 prompt 提交的附件**，约束语义更显式；配套社区资源位直接陈列 **CarPlay/Material 3/字节 Arco/HarmonyOS 官方级设计系统**作为可选附件源——"官方 DS 附件生态"是别家没铺的差异化。
3. **八阶段流水线营销叙事**：「Pixso 覆盖产品设计协作全流程」tabs=**产品规划→需求梳理→原型图→UI设计→设计系统→交互演示→交付→文件管理**——每 tab 切一个功能面板（白板 SWOT 等）。与六道门阶段（brief/reference/contract/build/verify/deliver）同构对照：**他们的八阶段=功能陈列旅程（无门无证据无停点），我们的六阶段=强制门+五级证据+人工裁决停点**——同形状不同物种，第四层（验证纪律）仍是我们独占。
4. **Figma 导入置顶导航**：迁移路径作为一级入口（与 hyperframes 的"Redraws Mermaid/draw.io"存量迁移同策略）。

## 可借鉴（③开发的依据）

- **a. 设计系统附件化**：本仓 design-contract 是"先契约后生成"的强制门，语义上已比"可选附件"更强；Pixso 的启示是**附件的可选清单可以陈列成生态**（社区 DS 资源位）——本仓无社区形态，不适用，仅记录。
- **b. 流水线叙事的功能面板化（对立卡）**：门径画布页每阶段已挂证据卡；Pixso 的 tab 切面板呈现启示=门径画布可加"阶段→证据面板"的 tab 化视图（现在是一屏长列）。立卡待排期（画布壳改动较大，属 workflow-diagram 壳升级）。
- **c. 本轮代码落地方向（语料→工具闭环第二例）**：51 轮 badge-legend-accessibility 语料对应的落地=产物墙徽章 aria 语义化+口径图例入页（增量 25）。

## 不抄什么

- "全流程覆盖"的营销式阶段叙事（无门无证据的阶段陈列=把流程当卖点而非约束；本仓阶段的价值恰在强制力）。
- 未登录 tooltip 式功能 teaser（"解锁更多功能"引导注册的钩子叙事）。
