# 服务条款与边界（Terms & Boundaries）

- 版本：v1 ｜ 生效：2026-10-19
- 说明：本文是本项目**公开、可复核**的服务边界声明，不是法律意见书。涉及具体商业合作时以另行签署的协议为准。

## 一、我们提供什么

UI Design Agent Kit 提供**一套 UI 设计智能体的工作流与验证纪律**：技能路由、六道门确认、证据分级、浏览器实测、产物墙与对比、离线复核包。产品形态是**指令层 + 验证层**，不是托管服务。

## 二、我们不提供什么

| 不提供 | 原因 |
| --- | --- |
| 模型推理服务 / API 额度 | 本 Kit 不承载模型；你使用自己宿主的模型 |
| 账户系统 / 云端存储 | 无后端；所有状态在本地仓库 |
| 生成引擎（图像/3D/视频） | 生成能力按契约外接，本 Kit 只做监管与验收 |
| 第三方素材授权 | 素材许可证由素材来源决定，需自行确认 |
| 商业可用性担保 | 代码按许可证提供；商用前请自行做合规评估 |

## 三、你的责任

1. **需求与方向**：门 A 确认后的方向由你负责；工作流不会替你决定产品要做什么。
2. **素材合规**：上传/引用的图片、字体、图标、数据必须你有权使用。本项目**不上传版权存疑的第三方素材**。
3. **对外发布**：本 Kit 的验收回执证明"在我们测过的条件下通过"，不构成对你线上环境的保证。发布前需在目标环境复验。
4. **密钥与凭据**：任何 API Key、Token 由你自行保管，不得写入仓库。本项目配置只引用环境变量。

## 四、我们能保证什么（以及不能保证什么）

**能保证（可复核）**：
- 每个产物附带**实测回执**：测了什么、在什么条件下、结果如何；
- 检视级别如实标注：`verified`（本项目实测）/ `unverified-partial`（仅公开渠道检视）；
- 未测维度记 `—` 或 `0/0 不适用`，**不虚记为通过**；
- 失败与降级**如实记录**，不隐藏。

**不能保证**：
- 任何具体设计一定"好看"——品味判断由你做出，工作流提供依据与选项；
- 外部能力（图像/3D/视频）的质量——它们按各自验收口径检查，不在本 Kit 控制范围内；
- 跨环境一致性——浏览器/字体/网络差异需在目标环境复验。

## 五、数据与隐私

| 项 | 做法 |
| --- | --- |
| 数据存放 | 全部在本地仓库；无后端、无遥测 |
| 竞品截图 | 仅作内部研究证据，**不上 showcase、不外发**（ADR-0002） |
| 品味档案 | 只记录可复核信号（你的原话/明确选择），不做心理画像；可要求删除 |
| 知识库 | 项目级机制卡，来源于公开内容判读；**不含你的私人数据** |
| 凭据 | 只引用环境变量，密钥不入库 |

## 六、能力接入的第三方条款

外接能力（图像生成、3D 建模、视频合成等）受其**各自许可证与服务条款**约束。本 Kit 的登记表（`canvas/capabilities.json`）记录每项能力的提供方与钉版，但**不为第三方行为负责**；接入状态为 `evaluating` 的能力不得用于交付。

## 七、可复核性承诺

本项目承诺：
1. 所有对外声明可在仓库内找到对应证据路径；
2. 演示产物与真实评测分开标注，不以演示冒充实测；
3. 发现自身错误时**公开更正**（在 iteration-log 留痕），不静默修改。

## 八、变更

本条款随版本演进；破坏性变更会在仓库提交历史与 iteration-log 中留痕。继续使用即视为接受更新后的条款。
