## 机制观察

1. **时长形态分层**：样片类集中在 20s–2:42，**「60 秒」是被命名的标准形态**（"60秒清晰传达产品功能亮点"出现在多条高互动标题）；3 分钟以上的只有教程类（30.8 万最高播放是《如何用AI制作精彩产品宣传片》，3:46）。
2. **三件套公式被点名词化**：最高互动标题（2.7 万，"看了800遍"）直接写"**音效+快闪字体+UI界面**完美配合"——音效设计/动态文字/UI 界面演示是宣传片的可复用三件套。
3. **单厂商垄断搜索页**：创意者动画制作公司一家占约 9/30 条，标题模板=痛点/赞叹句+功能点句式——与 79 轮丁小祥垄断「微交互 动效」同构，**关键词被单账号占满是该平台的内容生态常态**。
4. **品类三分**：①样片搬运（"动态设计样片/动态视觉鉴赏"号，西方官方片 repost——Lovable 2.0 页简介直接挂 YouTube 原片链接，标签 AE/3D/文本动画）②制作教程（播放量最高的一档）③官方号自宣（DocEasy，7591 播放）。**国内该品类的品质锚点是西方 motion studio 官方片，本地原创样片供给稀缺**。
5. **直接能力域信号（本轮最重要）**：jeffzhengye《AI视频导演级Skill：Codex装上它5分钟出电影感产品宣传片》（1959 播放，7 月发布）——**标签：Remotion / Claude Code / Agent Skill / Codex**。与 video-production 线同栈（Remotion）同范式（agent skill 产片），概念已公开存在且成教程。

## 判读

1. **受控编码路径（Remotion）已是 agent 产片的市场主流技术路线**——视频线方向被第三方独立验证；但**栈不是差异点**：对方卖"5 分钟出片"，我们的差异=工作流监管（证据链/守卫/六道门/品味档案）。能力域竞争已从"能不能做"转向"做得是否可控可复核"。
2. **60s 短版应是标准交付物**：官网 hero 可保留 165s 完整版，但传播单元（社媒/搜索场景）是 30–60s——立卡记录交付形态缺口。
3. **三件套缺口自查**：字幕（31 条）✓、UI 界面真实演示 ✓、**音效设计层缺失**（当前只有 BGM 无音效点）——这是与"高互动宣传片"公式的最大差距，立卡暂缓（受控编码内可做 whoosh/点击音效轨，待用户认可排期）。
4. 不抄：标题党句式（"看了800遍"/"至少少亏10w"/"5w一条"报价叙事）；搬运西方样片冒充自制。
