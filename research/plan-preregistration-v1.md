## 1. 研究问题与假设

**RQ-A（主）**：在 AI 辅助 UI 实现链路中，带人工监督门的工作流（意图确认 → 素材勾选 → 计划锁定 → 验收门+证据包）相对裸 prompt 使用，如何影响各验证维度（功能 / 视觉 / 交互 / 无障碍）的缺陷检出率、返工量与人工时间成本？

**假设**（H2 为确证性假设，其余为探索性——预先声明，防止事后挑结果）：

- **H1（探索）**：功能维度的缺陷检出在两条件下差异小（自动化检查可替代大部分人工功能验收）。
- **H2（确证）**：视觉 / 交互 / 无障碍维度上，门控工作流（含细节自评内环与分级证据包）的缺陷检出率高于裸 prompt 条件的人工自验。
- **H3（探索）**：门控工作流的首版通过率更高、修复轮次更少。
- **H4（成本侧，双向诚实）**：门控工作流消耗更多的人工监督时间；研究目标之一是量化这个"质量—注意力"交换率，而非只报质量增益。

**RQ-B（辅，可选第二实验，不并入主实验）**：证据分级（Installed → Visually verified 的分级证据包 vs 裸文本自述）是否降低验收时间、提高验收准确率。仅在主实验完成后视余力开展。

**测量框架说明（防过度声称）**：监督点 × 验证维度矩阵是**因变量的分解框架与探索性分析视角**，不是全交叉因子设计——N=10 不支持全交叉；主比较是"条件"这一自变量（2 水平，组内）。

## 2. 研究设计

- **组内设计（within-subject）**：每位参与者完成 2 个任务，分别在两个条件下；任务 × 条件用拉丁方平衡，条件顺序对半抵消。
- **条件**：
  - **C0 裸 prompt 基线**：同一模型、同一任务文本，自由对话式使用，参与者自行决定何时完成、如何验收；无强制门、无证据包。
  - **C1 门控工作流**：意图分析（乱需求 → 结构化需求卡，等确认）→ 素材候选勾选（含许可标注）→ 计划锁定 → 执行 → 验收门（分级证据包 + P0/P1/P2 问题清单）。"意图分析师"即条件内的第一个机制。
- **任务时长**：每任务上限 60 分钟（超时即停，按已完成部分评分）。
- **实验仪器**：最小硬 runner（代码强制）：条件分配、门禁状态机、计时、操作日志、证据落盘——四项全部不经 AI 之手。工作流内容仍走现指令层，不重写。

## 3. 参与者

- N=10：前端开发者约 5 人 + 非专家构建者约 5 人（记录专业度分层，作为协变量）。
- 纳入：有真实 UI 交付需求或经验；排除：参与过本 kit 开发或形成性访谈者。
- **形成性访谈（Phase 1）另找 3-5 人，绝不与实验参与者重叠**（先访谈后实验会污染）。
- 招募与知情同意由用户亲自执行；本机构无 IRB，论文中如实声明并附同意书模板。

## 4. 任务集

8-12 张标准任务卡（从旧 71 场景初选 12 个候选，见 [task-pool-candidates.md](task-pool-candidates.md)，Phase 3 冻结）。每张任务卡包含：

1. 任务文本（**口语化重写**，模拟真实用户口吻；不照抄旧场景原文——旧文本与系统共同设计，直接复用有偏差）；
2. 验收判据清单（按四维度组织，由评分者独立于参与者起草）；
3. 预期缺陷类型标注（依据旧执行记录中的真实缺陷谱：对比度、键盘链路、状态覆盖、语义漂移等）；
4. 适用条件说明（两条件均可执行）。

选择标准：单人 60 分钟内可完成；不依赖不可达服务；覆盖 ≥3 种 UI 类型；四维度均可评判。

## 5. 因变量与指标

**主指标**：

| 指标 | 定义 | 采集方式 |
| --- | --- | --- |
| 缺陷检出率（按维度分解） | 参与者验收时发现的真实缺陷 / 产出中全部真实缺陷 | 评分者事后对产物做全量缺陷普查（双评分者独立，报告 Cohen's κ），再比对参与者验收记录 |
| 人工监督时间 | 参与者花在确认/勾选/验收上的净时间 | 硬 runner 计时 + 门禁停留时间 |
| 返工量 | 修复轮次、变更规模 | 硬 runner 日志 + git diff |
| 产出质量 | 功能判据通过率 + 八维样式分（0-2/维） | 双评分者独立评分，报告一致性 |

**次要指标**：NASA-TLX 简版（每任务后）、7 点信任与满意度量表、条件偏好与理由（实验后访谈）。
**过程数据**：门禁停留时长、素材勾选行为、证据包查阅行为（用于解释主指标，不单独立论）。

## 6. 分析计划（预注册）

- 主检验：H2 —— 两条件下"视觉+交互+无障碍"合并检出率的组内比较（Wilcoxon 符号秩检验；N=10 功效有限，主报告效应量与描述统计，p 值为辅）。
- H1、H3、H4 按探索性报告，明确标注 exploratory。
- 双评分者一致性：Cohen's κ；κ < 0.6 的判据项剔除并如实披露。
- 监督点 × 维度矩阵：描述性热图，标注 exploratory，不做推断检验。
- **负面结果政策**：所有假设结果无论方向一律报告；不显著即写不显著。

## 8. 风险与降级规则（停止条件）

| 风险 | 触发 | 处置 |
| --- | --- | --- |
| 招募不足 | 实验期开始时 < 10 人 | 降至 8 人如实报告；< 6 人则顺延并重排期 |
| 硬 runner 延期 | 周 6 未完成 | 每人任务 2→1，转组间设计，功效下降如实报告 |
| 假设被推翻 | Phase 1 访谈显示 H2 前提不成立 | 回 Phase 0 修订假设并重新审定，不硬跑 |
| 单评分者缺席 | Phase 4 只有一名评分者 | 质量分降为单评 + 抽检复核，如实声明 |
