## 一句话定位

> **UI Design Agent Kit = 一个 UI 设计智能体 + 它的工作流**：通过 AI 调用技能（skills）、编排更好的工具（MCP/CLI/浏览器），把"一句口语需求"变成"有证据的可验收界面"——本质上是一个**用来生成更好产品工作流、并调度更优工具的智能体工作流**。

它不是研究项目本体。`research/` 是另一条研究架构线（研究适配层），按 2026-09-30"研究优先转向"裁决入驻本仓，但**不改变本仓的产品身份**。

## 是什么 / 不是什么（能力矩阵）

**是**：
- 一个项目级 UI 设计智能体：指令层（SKILL.md 体系 + 22 个技能）、有界工具编排（MCP 配置钉版）、六道门人工确认工作流
- 一套验证纪律：五级证据等级（Installed≠…≠VisuallyVerified）、161 项自动化测试、71 场景评测台账、浏览器实测强制
- 一个可迁移提示词工厂：`npm run prompt:build` 产出单文件提示词给其他宿主
- 12 个有独立 README/证据的线上案例

**不是**：
- 不是独立 AI 客户端/产品运行时（不提供模型服务、账户、付费素材）
- 不是运行时引擎/渲染框架（核心是智能体指令层+验证层，不假装有自动布局引擎）
- 不是 Figma 同步工具（设计源走 designContracts 品牌基线钉版通道，figma MCP 有意禁用）
- 不是 IDE 替代品（与 Cursor/v0 共存：本 kit 的价值在人机分工的确认门与证据纪律，不在生成能力本身）
- **不是研究项目本体**（research/ 是另一条研究架构线，见下）

## 研究适配层的地位（research/）

- **是什么**：一套独立的研究计划（预注册、P1-P5、测量仪器）+ 研究语料，研究"AI 界面构建中人工监督的价值"（RQ-A）。仪器把本仓工作流包装成 C0/C1 实验条件——**工具=实验载体**。
- **与本仓关系**：入住（2026-09-30 裁定），不改产品身份、不进产品运行时、不回流产品依赖。产品层与研究层通过"同一工作流被测量"这一关系单向连接。
- **物理去留（挂起，待裁）**：研究线最终是否迁出本仓独立成仓——**未决**。当前按"住在产品仓的独立架构线"管理：目录、测试、提交全部自包含在 research/ 与 tests/research-runtime.test.mjs。
