# 架构决策记录（ADR）

开发线关键裁决的沉淀目录。格式仿 ADR 惯例：背景 → 决策 → 理由 → 后果。

## 规则

1. 用户裁决一旦落地，随批新建一条 ADR（编号递增，不做静默修改）。
2. 重开一个已有 ADR 覆盖的议题前，先读该 ADR；推翻须新建 ADR 并注明取代关系。
3. **两仓分离**：本目录只记录开发线（本仓）裁决；研究线裁决一律记录在研究仓
   `uak-research/rulings.md`，不在此重复。
4. 每条 ADR 保持短小（≤60 行）；长论述放 `docs/` 对应主题文档，ADR 只留指针。
