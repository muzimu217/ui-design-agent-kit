## 三、可迁移模式（判据 3，五个维度）

| 维度 | 可迁移模式 | 迁移要点 |
| --- | --- | --- |
| 主体 | 程序化几何+皮肤贴图重映射（几何常驻、皮肤可换） | 皮肤系统与几何解耦 |
| 光照 | ambient 0.5 + directional 1.2 + 彩色 pointLight 点缀 | 三点最小集，无阴影也有体积感 |
| 相机 | 追尾视角+车道跟随（player.x 驱动相机 x 微移） | 相机随主体缓动，不硬锁定 |
| 交互 | 车道离散变道（目标插值）+ 连续 z 前进分离 | 离散决策+连续运动解耦 |
| 状态 | collide() 逐帧占据判定（AABB 简化版，无物理引擎） | 轻量判定够用就不上物理引擎 |
