# 微循环 GIF/WebM 导出（学习循环第七十二轮）

- 日期：2026-10-20 ｜ 点档：00（开发线）｜ 检视级别：**verified**（本项目产物实测）
- 对象：官网 stroke-art 描边循环动画（增量 40）的**微循环展示落地**（64 轮立卡闭环）
- 素材：27 帧连拍（virtual-time 采样）→ ffmpeg 合成

## 机制观察

1. **虚拟时间采样法可行**：Chrome headless `--virtual-time-budget` 按毫秒推进 CSS 动画相位——27 帧（budget 1000→4200ms，步长 200ms）覆盖完整 4.2s 循环；21 种不同帧字节证明动画真实推进（非同一帧复制）。
2. **产出规格**：WebM 52KB（640px，12 帧@6.4fps）/ GIF 595KB（480px）——**微循环文件 <100KB**，符合画廊嵌入成本约束（Motion 类 2-4s 自动循环形态，64 轮立卡参数）。
3. **首帧即品牌**：GIF 首帧 = 官网首屏完整视觉（标题/CTA/路径起始），单帧亦可作缩略图。
