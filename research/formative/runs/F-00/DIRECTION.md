## 形态论证（v2 新增，回应"能做成网页吗？网页做完有用吗？"）

- 需求本质：**每天定时桌面提醒 + 桌面常驻磁吸小组件 + 炫酷可换肤** → 目标形态 = **桌面应用**，网页是内芯技术不是交付形态。
- 网页的真实能力边界：UI、翻页钟、换肤、任务清单全部可做可验证；PWA 通知在 macOS Chrome/Edge 可用，但**后台标签页计时被浏览器节流、提醒依赖浏览器存活**——"网页后台听不到调令"的判断成立。
- 桌面壳选型：**Tauri 2**（本机 cargo 1.98.1 已核实 ✓；原生系统通知、常驻后台、无边框桌面窗实现磁吸贴，产物体积小）；备选 Electron（纯 npm 但运行时重）。
- 分期：**V1 = Web 核心**（React，浏览器完整可验证）→ **V1.5 = Tauri 壳**（系统通知 + 常驻 + 桌面磁吸迷你计时贴）→ **后续 = 课程表模块**（pending，不入本场）。
- 诚实边界：桌面壳行为（通知弹窗、磁吸）无法用浏览器证据链验证——该部分门E 降级为"用户亲手验收"，UI 层证据照常出。

## 动效意图（v2 升级）

- 计时数字 = **split-flap 翻页**（FlipClock 模式）：秒/分进位时上半叶翻落，真实机械节拍感
- 模式切换、按钮态：Snappy 弹簧 + 霓虹描边流光（流光仅作操作反馈，不常亮闪烁）
- 主题切换：背景交叉淡入 + 颜色 token 过渡（约 300ms，Elegant 曲线）
- `prefers-reduced-motion`：翻页降级为数字直切、流光关闭、状态即时更新
- 仍然不做：入场动画狂欢、无限循环装饰动效
