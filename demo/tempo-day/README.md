# Tempo 今日节奏

把任务和预计用时放在一起，选中一件事，开始专注。

## 能做什么

- 新增、编辑、删除任务，设置 1 至 180 分钟的预计用时。
- 按深度工作、日常事务和休息分类，查看当天时间分布。
- 开始、暂停、继续计时，完成任务或撤销刚才的操作。
- 在今日工作台和专注视图之间切换，保留当前计时状态。
- 刷新后从本机存储恢复任务和计时截止时间。

## 快速开始

推荐 Node.js 24。在仓库根目录运行：

```bash
cd demo/tempo-day
npm ci --ignore-scripts
npm run dev -- --port 5179
```

打开终端显示的本机地址。端口被占用时指定其他端口。

## 数据与限制

任务保存在当前访问地址的 `localStorage`。更换浏览器、端口或域名会使用不同存储；清理站点数据会移除本机计划。存储不可用时界面会提示。

计时通过截止时间计算剩余量，不依赖后台标签页按秒准时执行。关闭网页后不会发送系统通知；没有后台、账户、多人协作、日历同步或远程提醒。
