## 二、核心判读（研究产出）

### 判读 1：我们已有视频能力的"最后一公里"是叙事，不是渲染

Remotion 文档证明渲染链完备（4K/HDR/透明/SSR/Lambda），我们库内也有 remotion-* 技能族。**缺的不是技术，是"讲什么、按什么节奏讲"**。SideShift 的精确时间轴（每 12 秒一个 re-hook）与 60-15-6 策略正好补这一公里。

### 判读 2：那条 4K HDR 实录是我们的"同构参照物"，且提供了可复用的诚实指标

`BV1Xcpt6REr8` 的简介直接公开了 **127 Agent / 12,666 次工具调用 / 356 次报错**，并把"片尾图谱=真实制作记录"作为卖点。这与本仓"证据留痕"完全同源——**我们可以做同样的片尾制作图谱**，数据从 iteration-log 自动统计。

### 判读 3：Vibe Coding 的真实痛点是"认知空转"，不是"不会写代码"

高播放痛点内容（9420/8286 播放）指向：AI 让人从"体力劳损"转为"认知空转"——**看得见产出、看不懂过程**。这正是本仓白盒链路+门径要解的题，也是视频最该讲的故事。

### 判读 4："Message Beats Production Value"——我们不该做炫技片

Vidico 的核心结论与我们的品味档案（`trusts-evidence-over-hype` 0.80 已采用）**完全一致**。视频应当**克制、信息密度高、证据可视化**，而不是堆特效。

## 三、视频能力接入评估（契约四问）

| 问 | 答 |
| --- | --- |
| 谁产出 | Remotion（`remotion` 官方 skills，库内已钉版）+ three.js（如需 3D） |
| 边界在哪 | **能做**：代码驱动的确定性视频、4K/HDR、透明、字幕、参数化；**不能做**：AI 生成实拍素材、真人出镜、复杂三维建模（需外部资产） |
| 如何验收 | **视频口径**（非网页六维）：时长/帧率/确定性（同输入同输出）/音画同步/首帧可读/字幕对比度 |
| 证据落在哪 | 渲染回执 + 帧抽样截图 + 制作图谱（Agent 调用数/报错数） |

**接入结论：`adopted`（已有能力，补叙事规范）**。写入 capabilities.json。

## 四、方向指定（视频线）

1. **叙事模板**（本轮落卡）：Hook(0-3s) → Re-hook×3（每 12s）→ 证据段 → 制作图谱收尾；
2. **不做的**：不追 4K HDR 炫技（Message > Production Value）；不做真人出镜；
3. **官网重构**（本轮执行）：按"克制、信息密度、艺术画面"重做，为视频提供**可录制的真实界面**（视频里的"真实运行录屏"素材来源）。

- 不使用 CC0 之外的音乐素材（本仓不购买、不上传版权存疑素材）。
