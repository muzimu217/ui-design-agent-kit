## 提示词一：桌面端首页（1440×900，亮色）

为「竹与墨」个人技术博客设计首页首屏（桌面 1440×900，亮色模式）。

整体：纸感暖白底 #FAF7F0，墨黑文字 #1F2421，克制留白，安静的编辑器质感。
**背景层**：宣纸质感底纹上有淡淡的墨竹水墨画——竹竿与竹叶只沿页面左缘与
右下角分布（浓淡 8%–20% 透明度），画面中央留白干净保证正文可读；三两片
墨色竹叶正在缓缓飘落（画面定格在飘落中途，叶片带轻微旋转），传达常驻
背景动画的存在感。不要玻璃拟态、不要霓虹渐变。

布局从上到下：

1. 顶部导航（高 64px）：左侧圆形几何熊猫 logo（黑白几何熊猫抱一节竹子，
   眼罩为川剧脸谱式弧形、竹绿色 #2F6B4F 描边）+ 站名「竹与墨」（楷体）；
   右侧导航：首页 / 文章 / 随笔 / 归档 / 关于，最右日月主题切换图标。
2. Hero 区（≤60% 视口）：左侧大标题「你好，我是小墨」（楷体笔意）、副标
   「成都开发者 · 写代码、看番、啃竹子」、标签胶囊：Rust、前端、追番、成都；
   右侧扁平可爱风场景插画：竹林里熊猫趴在笔记本电脑前敲代码，插画微倾 2–3°。
3. 文章列表（非卡片墙）：加粗标题 + 日期 + 阅读时长 + 两枚小标签 + 两行摘要；
   标题与链接深竹绿 #2F6B4F；首条带朱砂红 #B5452F 描边「置顶」徽标。
4. 栏目条「追番周记」：横向窄条，左小幅熊猫看番插画，右栏目名+最新标题。
5. 页脚：细线分隔，归档 / RSS / 友链 + 趴着打盹的小熊猫图标。

交互暗示（静态图需传达）：一枚按钮 hover 态带"墨点晕开"的柔和晕染边缘；
一处列表项呈现淡入上浮中途（传达渐进显现）。
色彩令牌：底 #FAF7F0 / 墨 #1F2421 / 竹绿深 #2F6B4F / 竹绿亮 #52B788 /
朱砂 #B5452F（仅徽标）/ 科技蓝 #4E9BD8（仅代码示意）。
字体感觉：标题楷体带笔意（类霞鹜文楷），正文现代黑体，代码等宽。
氛围：安静、可读、藏不住的可爱；一切动效的气质都是"水墨的慢"。

## 提示词二：移动端首页（390×844，亮色）

同一博客的移动端首页（390×844），响应式重排而非缩放：

- 顶部窄条（高 56px）：熊猫 logo + 「竹与墨」+ 搜索图标；主导航移到底部。
- **底部标签栏**（高 64px，拇指可达）：首页 / 文章 / 随笔 / 归档 / 我的，
  五枚图标+文字，当前项竹绿高亮。
- 首屏：紧凑 hero（标题一行、副标一行、横向可滑动标签胶囊），背景墨竹
  只在顶端与底缘淡淡出现；第一篇文章卡片必须在首屏内露出。
- 文章流：单列紧凑列表（标题/日期/标签/摘要一行半），滚动到中部。
- **画面底部停在"上拉加载"状态**：一只小熊猫抱着往上生长的竹节加载指示
  （两节竹子+待生长的虚线节），文字「上拉加载更多」。
- 竹叶飘落背景同样存在（边缘、低透明度）。
- 按钮与列表的墨晕/淡入暗示与桌面端一致；文字字号与桌面同级，不做缩放。

## 提示词三：墨竹背景动画艺术稿（1280×800）

一张"墨竹"动态背景的关键帧艺术稿（1280×800）：

- 宣纸米白底（#FAF7F0 打底的纸纹），传统水墨墨竹构图：数竿竹从左下与
  右上角斜出，竹竿有节、笔触有浓淡枯润变化（毛笔侧锋与中锋并存），
  竹叶三五成组、疏密有致，中央大面积留白。
- 画面定格动画瞬间：一片竹叶脱离枝头飘落至半空（带旋转），另一片刚落定
  在地面化作淡墨渍；一根新竹竿的笔触正画到一半（笔锋未收），传达"墨迹
  实时生长"的动效意图。
- 墨色层次：焦墨（竹节）、浓墨（近叶）、淡墨（远叶）、极淡墨（背景晕染）。
- 整体安静、克制、可作网页背景（内容区不会与竹冲突）。

英文一行版：traditional Chinese ink wash painting of bamboo on rice paper,
brush strokes with rich ink tonality (dry and wet), a leaf mid-fall with gentle
rotation, one brush stroke half-drawn conveying live ink growth, large negative
space in center, serene, web background keyframe, 1280x800

## 门C 判据（v2，出图后对照）

- [ ] 第一眼是内容与可读性，熊猫/插画/墨竹是身份不是噪声
- [ ] 桌面：hero ≤60% 视口，文章前两条可见
- [ ] 移动：底部标签栏可达，首条文章露出，"上拉加载"竹节指示清晰
- [ ] 墨竹背景：只在边缘、浓淡克制、中央留白（文字区不被干扰）
- [ ] 动效气质统一为"水墨的慢"：墨晕 hover、淡入上浮、飘叶、竹节加载
- [ ] 两种声音分层：插画层（いらすとや感）≠ 图标系统层（几何熊猫）
- [ ] 朱砂红只是徽标级点缀；竹绿深浅两档都出现
