## ① 9 天增量（相对 2026-10-07 首检）

1. **"Agentic by default" 上首屏卖点**："v0 plans, creates tasks, and connects to databases as it builds"，配 Web/LLM/Plan/DB/API/Deploy 管线图——**"先计划再建"从内部行为升级为第一屏承诺**（Vercel 级别玩家的背书）。
2. **"Create design systems" 成为官方特性**："Define colors, typography, and styles that you can use across projects"——设计系统前置家族 **收敛 ×2→×4**（bolt.new→Pixso→Onlook→v0），Vercel 是家族最重成员。
3. **Design mode**："Edit with design mode — visual controls and live preview"——v0 向可视化编辑渗透（侵入 Onlook 所在层）。
4. **渠道聚合**："Use your ChatGPT plan in v0"（OpenAI 计划互通）+ 模型选择器（v0 Max）+ iOS app + Students 项目——分发面猛扩。
5. **Repo sync**："Connect to GitHub and push code directly to your repository."

## ② 机制研判

- **层间渗透加速**：v0 一家同时吃设计系统（Pixso/bolt 方向）、可视化编辑（Onlook 方向）、agentic 计划（Lovable/agent mode 方向）、移动端——生成层巨头正把四层图谱的 1-3 层熔进一个产品。
- **第四层仍无人占据**：整个落地页没有"人工确认门"“验收证据”“可审计交付"的任何叙事——v0 的计划是 agent 内部行为，用户只能看结果。**kit 的生存位主张经复检无变化且更清晰**：层 1-3 越是熔成超级平台，"独立于任何生成器的验证纪律层"越稀缺。
- **D8 升级**：Unity 老易的"先计划再写码"获 Vercel 机制侧印证（roadmap D8 行已同步，注明 HITL 缺口仍在）。
- 首检立卡（门 C 版本对比规范）维持待门 A；v0 未提供新信息改变其暂缓理由。

## ③ 可借鉴 / ④ 不抄

- 借鉴：**"plans, creates tasks" 的措辞方式**——把过程纪律说成能力承诺；我们表述门 A/计划锁定时可参考这种"承诺式"语言（表述借鉴，非功能引入）。
- 不抄：模型选择器/渠道聚合（无模型服务）；iOS 端（超范围）；把计划藏在 agent 内部（恰是我们的反面——计划必须冻结在人可否决的节点上）。
