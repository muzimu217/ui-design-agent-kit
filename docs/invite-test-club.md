**标题**：【测试招募】用你的 AI 编码智能体跑一次"会停在门口"的 UI 设计流程

**正文**：

各位同学：

我们在维护一个开源项目 **UI Design Agent Kit（UAK）**——一套给 AI 编码
智能体（Claude Code / ZCode / Codex 等）用的 UI 设计流程指令集。它刚刚
完成一轮架构升级（吸收蚂蚁开源 agentUniverse 的多智能体协作机制），
招募首批测试用户，特别欢迎社团成员参与。

**它解决什么问题**

AI 写 UI 很快，但常见毛病是：跳过需求确认、素材来源不明、凭空原创、
"生成完成"就当"验收通过"。UAK 给智能体立了六道门的规矩：方向稿→素材
清单→原型→设计契约→验收→留痕，每道门必须停下来等你裁决；验收发现
必须附实测证据（截图/对比度实测值），不许自报满分。

**测试任务（约 30 分钟）**

1. 按仓库 README 把 kit 装进你的智能体环境；
2. 随便挑一个小 UI 需求（比如"做一个番茄钟单页"）发给智能体；
3. 观察并记录三件事：
   - 它是否**先停下**来呈交方向稿等你裁决，而不是直接开写代码？
   - 素材是否给出**真实来源 URL 和授权说明**？
   - 交付时是否附**真实截图与测试证据**？

**反馈方式**

在本 issue 下回复你的观察（哪个环境、哪一步停/没停、截图更好），
或直接在主仓库开 issue。我们特别想知道：哪些口语化需求会让它忍不住
跳门——那是我们最需要的加固素材。

仓库：https://github.com/muzimu217/ui-design-agent-kit
（纯提示词工程：不装运行时、不要 API key、不改全局配置）
