Onboarding Console · 接入工作台

把 UI 设计智能体装进你的 Agent

UI Design Agent Kit 是一层工作流指令——装进你已有的 Agent 宿主（Codex、Claude Code、Cursor…）后， 它按六道门工作流干活：需求确认 → 素材核对 → 原型 → 契约实现 → 真实浏览器六维验收 → 带证据交付。 三层适配：单文件提示词（万能）/ AGENTS.md 接入（幂等）/ 技能目录直装。

STEP 1

装 Kit（一次性）

任意目录安装。uak-init 命令全局可用。

npm install -g github:muzimu217/ui-design-agent-kit

Node ≥ 20.18.1。安装后自动带 uak-init 命令（已实测：shebang+符号链+路径解析三重修复）。

STEP 2

接入你的项目

cd 到你的项目根目录，一条命令接入（幂等，不碰你已有内容）。

uak-init

自动探测宿主（.codex/→Codex，CLAUDE.md→Claude，其余→通用）。加 --dry-run 预览、--check 体检。

STEP 3

开干（Express 档）

在你的 Agent 里说第一句话，10 分钟内拿到第一张验收截图。

对本项目首页做一次只读验收，给出证据清单

首轮先注入 .agents/uak-prompt.md（接入时自动生成）。方向稿会停在门前等你确认。

你的宿主怎么接

点击查看该宿主的具体路径。同一套工作流，不同的注入方式——一层转换、多次输出。

诚实边界：本 Kit 是工作流指令层，不是独立产品——它不提供模型、账户或托管。 宿主仍需自备模型服务与 MCP；缺什么，uak-init 的接入说明会列清楚，不会假装已连接。 证据与验收记录留在你自己的项目里，全部本地可复核（131 项测试 / 73 场景台账 / 五级证据等级）。
数据来源：scripts/uak-init.mjs 实测行为（2026-10-10 全局安装三重修复后）；宿主适配边界见 ADR-0003；产品定位见 identity-and-direction.md。
