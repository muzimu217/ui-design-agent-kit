# DESIGN.md · 习惯打卡单页工具（P-habit-2 · 精简契约，随代码交付）

依据：门A/B/C 已过裁决；品味修订 T-008（个人安静工具：不用玻璃磨砂、不用高饱和活力蓝）；
motion-contract.md（Snappy 预设）；A5 单文件自包含形态（无构建、无运行时依赖）。

## Mission

给自己的习惯打卡工具：每天打开 ≤30 秒完成打卡，看到本周七天与连续天数。
安静、低刺激、零学习成本；数据只在本机浏览器。

## 语义 token（:root，实测对比度见 docs/ACCEPTANCE.md）

```css
--paper:#f5f4ef;      /* 页面底：暖纸灰 */
--surface:#ffffff;    /* 行/卡面 */
--ink:#2b2a25;        /* 主文字 */
--muted:#6f6d63;      /* 次要文字 */
--line:#e3e2d9;       /* 发丝边 */
--accent:#84552a;     /* 今日/焦点：赭棕（低刺激，非活力蓝） */
--c-sage:#647a52;  --c-clay:#96613a;  --c-slate:#5d7787;   /* 每习惯色（降饱和） */
--c-plum:#7d5a6e;  --c-teal:#4f7d6d;  --c-ochre:#8a7434;
--r-s:6px; --r-m:9px; --r-l:14px;
/* 间距 4px 基：4/8/12/16/24；字号 11/12/13/14/15/17/22 */
```

- 每习惯一色 = 完成格填充 + 行首圆点；白对勾画在色上（非文字 UI 边界 ≥3:1，实测）。
- 单一亮主题；不支持暗色（未要求，Do 条明确不加）。

## 动效（Snappy 预设；无运行时依赖的 CSS 落地）

| 角色 | 属性 | 参数 |
| --- | --- | --- |
| 打卡格填充/撤销 | background-color、border-color | 140ms `cubic-bezier(0.16,1,0.3,1)`（契约批准的非弹簧曲线；语义类切换即时，动画纯表现层） |
| 对勾出现 | transform scale .6→1 + opacity | 160ms 同曲线，keyframes 一次 |
| 按压（含键盘 :active） | transform scale .96 | 120ms 同曲线 |
| 连续徽标更新 | transform translateY(-3px→0) | 140ms 同曲线 |
| hover | border-color 加深 | 120ms（onset ≤150ms） |

- **红线**：禁 `transition: all`；语义状态（aria-pressed、计数、存储）永不等待动画；
  连续快速切换必须保持语义正确（每次点击即改状态）。
- **reduced-motion**：`prefers-reduced-motion: reduce` 下全部 transition/animation 关闭，
  语义终态即时呈现。

## Do / Don't

Do：安静低刺激、信息密度低、留白充足；一眼看到今天列与连续数；删除/清空必须确认；
空状态教操作；白话文案；数据边界写进界面（"仅存本浏览器"）。
Don't：不用玻璃磨砂、渐变、阴影堆叠、高饱和主色（T-008）；不加暗色主题与装饰性插画；
不做卡片套卡片；不为动画加依赖；不虚构能力（不显示"云同步"等）。
行为说明（门E 代行裁决 2026-09-20）：编辑示例习惯即视为采纳该习惯，"示例"标记随之移除。

## 验收门（门E，每轮）

1. 主旅程：打卡→撤销→补卡（切周）→增改删→清空示例→空态→再加，全部真实可用且持久化（重载后一致）。
2. 对比度实测：正文 ≥4.5:1；完成格白勾/色底等非文字边界 ≥3:1（脚本测，不目测）。
3. 键盘全链路：周导航/打卡/增改删/对话框（焦点包含与返回）/清空，均可达且有可见焦点。
4. 响应式：375×812 / 768×1024 / 1440×900 无横向滚动、无遮挡、长习惯名换行不破格。
5. 动效：常规与 reduced-motion 各查一遍；快速连点/撤销语义正确。
6. Console 干净（无 error/warning）。
