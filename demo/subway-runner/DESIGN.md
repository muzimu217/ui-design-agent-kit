## Mission（一句话）

玩家控制主角在地铁轨道上向前狂奔：换道、跳跃、下滑铲躲障碍、吃金币，
身后有追捕者，被抓住或正面撞上列车即结束，比拼距离与金币数。

## 场景与状态机

```text
TITLE(开始界面) → RUNNING(跑动) → STUMBLE(绊一下,可恢复) → RUNNING
RUNNING → CAUGHT(被抓住/正面撞击) → GAME_OVER(结算) → RETRY → RUNNING
```

- 跑道：**3 条车道**（左/中/右），两侧为隧道墙/站台边缘，向前无限延伸。
- 主角固定在屏幕下方约 1/3 处，世界向玩家移动（经典跑酷相机）。
- 追捕者（警卫 + 狗）平时贴在画面下缘；玩家绊倒时逼近一段距离，
  恢复奔跑后逐渐掉出画面——用「距离条」或画面内的实际位置表达紧张度。
- 失误判定（判死规则）：擦碰/侧碰低栏或限高门 = **STUMBLE**（绊一下，
  追捕者逼近一格，短时间内再次失误即被抓住）；**正面撞列车、或在追捕者
  贴身时再失误 = CAUGHT**（直接结束）。
- 生成不变量：任意时刻前方障碍布局必须保证**至少一条车道可通行**；
  金币串不得与障碍体积重叠（跳跃弧线串只出现在低栏正上方）。
- 障碍四类：低栏（跳过）、限高门/横杆（下滑铲过）、静止列车（换道）、
  迎面列车（必须换道，带灯光警示）。
- 金币：按车道成串排布，直线串 / 跳跃弧线串两种。
- 速度随时间递增（有上限），HUD 显示距离分数与金币数。

## 操作与输入

| 输入 | 动作 |
| --- | --- |
| ← / →（或 A/D） | 换道（弹簧插值，可中途反悔） |
| ↑ / W / 空格 | 跳跃 |
| ↓ / S | 下滑铲（空中按下 = 快速落地接铲） |
| 触屏滑动 | 四方向等价手势 |
| Esc / P | 暂停 |

## 动效意图（motion intent）

- 换道：弹簧插值（保留横向速度、可被打断续接），不是匀速滑动。
- 跳跃/铲：抛物线 + 落地压缩（squash & stretch 一帧）。
- 金币：自旋 + 拾取时向 HUD 计数处上飘消散（1–2 个粒子即可）。
- 追捕者逼近：镜头轻微下压 + 下缘红色警示渐入（脚步声的视觉替代）。
- 速度感：伪透视下沉点随速度微移（等效 FOV 变化）；`prefers-reduced-motion`
  时关闭镜头晃动与屏幕震动。
- 被抓/撞击：0.6s 慢动作 + 画面拉近 → 转结算浮层。

## HUD 与浮层

- 跑动中 HUD：左上距离分数（大）、金币数（带图标）、右上暂停。
- 标题浮层：游戏名、开始按钮、操作说明（首次展示）。
- 结算浮层：本局距离 + 金币、最佳纪录（localStorage，本地示例数据）、重开按钮。
- HUD 为 DOM 覆盖层（不进 canvas），沿用 kit 语义 token 与焦点可见性。
