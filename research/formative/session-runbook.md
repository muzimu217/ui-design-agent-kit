# 形成性访谈执行手册（session-runbook.md，P1-4 配套）

- 日期：2026-10-01 ｜ 用途：访谈当天的操作流程，用户照此执行；预计 1-2 天内完成 3-5 场
- 配套：[interview-protocol.md](interview-protocol.md)（提纲）｜[recruitment-formative.md](recruitment-formative.md)（名单表）

## 场前（提前 10 分钟）

1. 名单表里给受访者编 F-0x 号，核对其**不在实验池名单**。
2. 会议软件开**双录**：平台录音 + 本地录屏（屏幕留访谈提纲即可）。
3. 打开提纲和单人记录模板，填好编号/日期。
4. 浏览器开一个空白页备用（对方要演示项目时让其共享屏幕）。

## 场中（45-60 分钟）

1. **开场话术**（照读，30 秒）：
   > "今天就是聊天，没有对错答案，你平时怎么用就怎么说，讲具体的事最好。我们会录音，只用于研究、完全匿名，刚才已确认同意。那我们开始。"
2. 照提纲五部分走，顺序可调；**每个主问题追到具体例子为止**。
3. A 部分（最近一次经历）时间给足（20 分钟），这是数据主体。
4. D 部分（确认门概念）前提醒："接下来我讲个设想，你听完直接说真实想法，嫌烦就说嫌烦。"
5. 不介绍、不评价我们自己的系统；对方问"你们是不是做了个工具"→ 答"研究完成后细说"。
6. 随手在记录模板记**逐字引语 + 大致时间点**（比事后回忆可靠）。

## 场后（当天内）

1. 导出录音 + 录屏，文件命名：`F-0x-audio.m4a` / `F-0x-screen.mp4`。
2. 转写（会议自动转写导出，或手理）存为 `F-0x-transcript.md`，格式：

```markdown
# F-0x 转写（日期 / 时长 / 受访者类型：A前端|B非专家）
[00:12] 我：……
[00:31] 对方：……（逐字，方言口语保留，不改写）
```

3. 当天把**转写 + 记录模板页**发给主代理 → 进 P1-5 编码。
4. 每场结束在名单表更新状态；前 2 场后若有追问微调，在提纲版本记录里注明（主问题不动）。

## 回传清单（每场）

- [ ] `F-0x-transcript.md`
- [ ] 记录模板页（关键引语/失败模式初标/待跟进）
- [ ] 对方自愿提供的聊天记录或截图（有则匿名后附上）
- [ ] 名单表状态已更新

## 提醒

- 一天最多 2 场，间隔留休息——访谈质量比赶进度重要。
- 出现计划外的重要话题（如成本、团队协作）自由跟进，事后在记录页标注"计划外"，编码时一并入册。
