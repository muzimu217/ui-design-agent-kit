# 对标洞察：Lovable——第三轮学习循环

- 日期：2026-10-07 ｜ 检视级别：**unverified-partial**（实看落地页一张截图 + 首屏 DOM 探查；GitHub 同步/Visual edits/Knowledge 等为其公开宣传口径，未实机验证）
- 证据：`landing.png`

## 机制观察

1. 定位已从"生成应用"上移到**平台能力叙事**：首屏功能区列 Analytics / **Cloud** / Connectors / Security / **Agent integrations**——卖后端与集成，不再只卖"AI 生成页面"。
2. 公开口径（未实机）：GitHub 双向同步、Visual edits（所见即所得改）、Knowledge（项目记忆）。
3. 三家横评一句话：v0 卖**迭代透明**（版本/回滚）、bolt 卖**前置控制**（设计系统/Plan/成本档）、Lovable 卖**工程化平台**（同步/云/记忆）。

## 对照我们

| 他们收敛到的方向 | 我们的对应资产 | 差异化判断 |
| --- | --- | --- |
| 项目记忆（Knowledge） | 品味档案 + 门账本 + 迭代日志 | 他们的记忆服务于"少重复说"；我们的记忆服务于**可审计**——保持差异 |
| GitHub 同步 | 本仓即 Git 原生 | 无需借鉴 |
| Visual edits | 门 C 原型 + 细节自评内环 | 值得**立卡观察**："指哪改哪"的交互是否该进 C1 条件的验收轮（门 A 议题） |

## 不抄

- 平台化叙事（Cloud/Connectors/Security）与本仓定位（工作流+研究）正交；跟进去就丢了"帮人设计 UI 的工作流"身份。

## 反馈

- K1=本卡（三家横评初步成型）；K2=立卡（Visual-edit 式交互进 C1 的评估，门 A 议）；K3=本目录截图。
- 下轮对象预告：GitHub Copilot Workspace / agent mode（"规划→执行→监控"叙事）或 Figma Make。
