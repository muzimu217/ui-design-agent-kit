## 展示内容

- 产品首屏与特性介绍。
- 规格表、锚点导航和窄屏菜单。
- 本页购买意向的前端反馈。

## 快速开始

推荐 Node.js 24。在仓库根目录运行：

```bash
cd demo/product-demo
npm ci --ignore-scripts
npm run dev -- --host 127.0.0.1 --port 5183
```

打开终端显示的地址；端口被占用时换一个端口。

## 演示边界

没有实体商品、健康监测能力、支付、真实订单或云端存储。页面中的续航、防水和传感器描述只是示例内容，不是经过测试的硬件性能或医疗建议。意向按钮仅改变当前页面状态。
