## 3. 数据管理声明 v1

- **存放**：原始件 `research/formative/data/`（P1）与 `runs/`（P4，R5 封存 + sha256 清单）；分析数据冻结后不可变（防 peeking，预注册 §5）。
- **访问**：研究者（作者）与 rater-2（独立评分者，签署保密承诺）；无其他访问者，不使用第三方云分析服务。
- **开源范围**：匿名会话包（产物、日志、timing、问卷、门决策记录）随论文发布；录屏原始件与排期表**永不**开源。
- **删除请求**：参与者随时可要求删除——排期表条目、对应 run 目录与开源包中的会话整体撤下（开源包以版本化方式发布，撤下记录公开说明）。
- **利益声明**：单作者，系统作者即研究者——论文 Limitations 明示，以双评分者独立评分、盲评拆封时点（评分全部完成+κ 计算完+共识清单冻结后才拆条件对照）与预注册对冲。

## 4. P1 补正条款（回溯性披露）

P1 问卷渠道（腾讯问卷）回收端自动记录了国家/省/市与 IP，与投放页口头告知"匿名编号保存、不公开身份信息"**不完全一致**。补正措施：

1. 已落盘 P1 语料的地区字段仅存于 `raw/` 原始件（只增不改），编码/备忘录/任务卡**未引用**任何地区信息。
2. 后续 P2/P4 问卷投放：同意话术补一句"问卷平台会记录您的 IP 与地区用于防刷，分析时不会使用"；或改开匿名设置（关闭 IP/地区记录）——执行时二选一，优先后者。
3. 本补正作为方法透明项写入论文 P1 局限说明。
