## 一、阻塞判定（具体到缺什么）

| 需要 | 现状 |
| --- | --- |

## 二、替代方案（显式声明为不等价）

| 方案 | 能做 | 与 .blend 的差距 |
| --- | --- | --- |
| **A. 程序化 Three.js 餐厅场景**（GLB/Web 可交互） | 可浏览可交互的 3D 场景，几何/材质/灯光全代码化 | **不可在 Blender 中编辑**；无建模历史；非 .blend 格式 |
| **B. 授权资产改用**（Sketchfab/poly.pizza CC0/CC-BY 餐厅模型，检索可见） | 真实建模师作品，GLB 可 web 呈现 | 不可编辑 .blend；授权条款需逐模型核查；风格受限于在库资产 |
| **C. 你本机装 Blender 后我出 Python 脚本**（bpy 程序化建模脚本，你在 Blender 内运行生成场景） | 可产出真正可编辑的 .blend（脚本=建模历史的代码化） | 需要你安装 Blender（约束外的一次本机动作，由你决定）；脚本调试往返成本高 |

**三方案均不等价于可编辑 .blend 交付**——如需严格 .blend，方案 C 是唯一路径，
但需要你解除"不安装"约束或自行执行安装。
