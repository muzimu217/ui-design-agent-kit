## 实际浏览器检查

使用隔离 Chromium，不连接个人浏览器资料。所有测试文件和存档都是本次测试生成。

- 桌面：实际点击画布放置；相机拖动释放不增加积木；坐标放置、移动、复制、改色、拆除、取消、撤销和重做；40 -> 42 块的编辑作品保存后刷新恢复。
- 关卡：分别通过真实按钮操作完成小屋 15、火箭 11、城堡 20 块目标，颜色改变不阻断匹配；切回自由模式保留作品；保存四模式草稿后重新加载仍可恢复。
- 手机：390x844、触控上下文，点击画布仅设置预览，点击确认才从 40 变为 41 块；积木盒展开占用真实高度，收起后恢复画布。可见按钮测量未发现小于约 44px 的目标。
- 视口：1440x900、1280x800、768x1024、390x844、320x740 的截图与页面宽度检查，无页面级横向溢出。320px 展开积木盒后画布较小，但主体完整可见。
- 键盘：Tab 可达选砖、坐标、确认和工具；Space/Enter 完成放置，快捷键撤销/重做通过；原生对话框约束焦点，Escape 后回到发起按钮。
- 原生 select 的键盘选项操作未完成验证：当前无头环境在单独的裸 select 上同样不能驱动弹出选择，事件未被应用取消。程序化 selectOption 和指针编辑路径通过；保留人工键盘复验项。
- JSON：真实下载后通过领域校验，42 块作品再导入成功；未知版本导入被拒绝，现有作品不变。
- PNG：真实下载并打开 1188x544 图像，包含完整作品和底板，不含预览/选择辅助，图像主体非空。
- 动画：正常放置的早期/稳定画布存在局部像素变化；减少动效对应两帧像素完全相同，语义数量均从 40 变为 41。
- 字体：逐元素将实际字号放大两倍进行压力测试，修复积木标签越界；12 项标签底边均位于按钮内。此测试不是浏览器原生缩放认证，也不代替所有页面状态的 200% 测试。

## 像素、对比度与性能

- 桌面/手机/积木盒展开状态均检查主体区域像素分布及截图；不是仅检查 canvas DOM 节点。
- 文本/控件色对：主文字与纸面约 12.44:1，次文字与工作台约 4.60:1，保存按钮文字约 5.58:1。不是全站无障碍认证。
- 200 块简单积木、1440x900、隔离桌面 Chromium：在已捕获的鼠标手势内合成持续旋转事件，记录 84 个有效帧间隔；中位数 16.7ms、P95 16.8ms。
  这是该场景下的浏览器 RAF 节奏，不是 GPU 耗时，也不代表 400 块复杂模型或手机真机帧率。
- 控制台已修复 favicon 404 和项目内 PCFSoftShadowMap 弃用；仍可能出现 R3F 使用 Three.Clock 的依赖弃用警告。没有通过屏蔽日志伪装干净结果。
