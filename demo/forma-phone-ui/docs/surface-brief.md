# Surface Brief: FORMA One Configure + Buy

Mode: Persuade

Audience: shoppers evaluating a premium smartphone on a phone or laptop.

Job: understand the object, choose a finish and storage, see the consequence, and add one configuration to a demo shopping bag.

First-surface proof: a phone can feel like a material object while configuration remains explicit and trustworthy.

Visitor path: identify product -> inspect render -> choose glaze -> choose capacity -> read live total -> add to bag -> optionally reset.

Signature interaction: selecting a glaze changes the phone's ceramic back and the labeled recipe strip; selecting capacity changes the price and shelf metadata.

Content boundary: all prices, specs, and status labels are illustrative fixture data. There is no checkout, inventory, account, review, or backend claim.

Responsive intent: on 375px, preserve the render and purchase action before secondary content; on 768px, use a balanced two-column configuration; from 1024px, keep a max-width shelf composition with the summary rail visible.
