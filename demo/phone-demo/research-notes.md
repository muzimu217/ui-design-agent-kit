## 1. 三个模式的要点提炼与适用性评估

### 1.1 pricing-page-cta（定价页 CTA 模式）

**要点提炼：**

- **Section Order**：Hero（定价主标题）→ 价格对比卡片 → 特性对比表 → FAQ → 最终 CTA
- **Primary CTA**：每张卡片各自 CTA + 导航栏 sticky CTA（双重入口）
- **Color**：层级色（免费=灰 / 主打=蓝 / 高配=金绿），卡片 1px 边框 + 阴影
- **Conversion**：突出目标人群的方案、透明展示「年度节省」、FAQ 打消顾虑

**适用性评估（针对高端智能手机单页产品页）：**

- 核心适用。手机产品页本质上就是「一个主推 SKU + 可选配置（容量/颜色）」，其「价格对比卡片 / 分层方案」可映射为 **「标准版 vs 旗舰版」或「裸机 vs 套装」的选择卡**。
- 「透明展示节省」→ 适用于 **首发优惠 / 以旧换新 / 套装省 ¥X** 的数字化表达。
- FAQ 前移（在购买区附近）可直接复用，打消「保修 / 分期 / 发货」顾虑。
- sticky CTA 适用于长滚动页，但移动端注意高度与遮挡。

### 1.2 ai-personalization-landing（AI 个性化落地页模式）

**要点提炼：**

- **Section Order**：动态 Hero → 相关特性 → 定制化证言 → 智能 CTA
- **注意点**：需要分析**集成方式与回退方案**（个性化内容不渲染 / 加载失败时要有默认内容）

**适用性评估：**

- 部分适用。「动态 Hero」对手机页有价值的是：**根据入口（如广告位、推荐来源）微调主卖点文案与设备渲染图角度**；证言可做「用户场景定制化」——按不同人群（商务/影像/游戏）展示对应 KOL 证言。
- **回退方案是硬要求**：SSR/降级时必须保证所有用户看到完整、无布局抖动的默认 Hero 与默认证言；这正好呼应 1.3 的静态快照要求。
- 不建议做重个性化（登录、追踪）——单页产品页首屏速度优先，轻量做「人群场景切换」即可。

### 1.3 real-time-operations-landing（实时运营落地页模式）

**要点提炼：**

- **Section Order**：Hero（产品 + 实时预览）→ 关键指标 → How it works → CTA
- **Color**：深色 / 中性 + 状态色（正常/告警等）
- **无障碍要求（重要）**：
  - live 数据必须**标注更新时间**与**陈旧（stale）状态**
  - 提供**暂停 / 隐藏控制**
  - **键盘可用**
  - **reduced-motion 下渲染静态最终快照**

**适用性评估：**

- 选择性适用。手机页的「实时预览」可替换为 **设备示意 / 产品渲染的动效演示**（如光影转动、拆解动画），而非真正实时数据。
- 若页面上有**演示数据 / 模拟计数器**（如「预约人数」），必须明确标注为演示数据并给出更新时间，遵循本模式的无障碍规则。
- 深色 + 中性 + 状态色的配色逻辑，与高端手机「深空灰 / 黑」调性高度契合，可作为主视觉基调（见第 2 节）。

## 2. 推荐方向：页面结构、主色、CTA

### 2.1 页面结构建议（自上而下）

1. **Hero**：主卖点一句话 + 设备示意图（产品渲染，可做轻度光影动效）
2. **特性区**：3–4 个核心卖点（影像 / 性能 / 续航），图文交错或卡片
3. **规格表**：完整参数规格（对比表或单机明细）
4. **购买 / 意向区**：价格卡（标准/高配）+ 首发优惠 + FAQ 收尾
5. **页脚**：常规链接、客服、备案等

> 采纳 pricing-page-cta 的 Section Order 骨架（Hero → 对比/特性 → 规格 → 购买/FAQ → 最终 CTA），并把「价格对比」放在规格表之后更贴手机单页的浏览习惯。

### 2.2 主色建议

- 底色：**深色或中性**（深空灰 / 近黑，或浅色系中性灰），大面积留白 + 1px 边框细节（呼应 pricing-page-cta 的卡片描边）。
- 主色：**一个主色**（建议冷调蓝或品牌金绿，来自 pricing-page-cta 的层级色逻辑）用于：
  - 主 CTA 按钮
  - 关键数字 / 指标高亮
  - 状态色（如「有货 / 已售罄」）
- 避免多色堆砌；强调色只服务「行动 + 状态」。

### 2.3 CTA 策略

- **双入口**：Hero 主 CTA + 导航 sticky CTA（滚动后可见，移动端折叠为悬浮按钮）。
- 每个价格/配置卡自带 CTA，文案用**收益导向**（如「立即预订」→「锁定首发优惠」）。
- 购买区附**打消顾虑**内容：保修 / 分期 / 发货 / 以旧换新。
- 最终 CTA 区：FAQ 之后给一个收束 CTA（回到预订 / 联系客服）。

## 3. 无障碍与动效注意

（提炼自 real-time-operations-landing）

- **reduced-motion**：所有动效（Hero 光影、卡片浮起、滚动揭示）必须在 `prefers-reduced-motion` 下**降级为静态最终快照**，保证信息完整可见、无布局抖动。
- **键盘可用**：sticky CTA、价格卡选择、FAQ 折叠均可 Tab 聚焦并可用回车/方向键操作。
- **演示/实时数据标注**：页面若含模拟数据（预约数、库存、日期倒计时），必须**明确标注「演示数据」并附更新时间**；提供**暂停 / 隐藏**控制（如倒计时可暂停、模拟计数器可隐藏）。
- 其余通用项：色彩对比度（状态色与深色底需达 WCAG AA）、focus 可见样式、文本可缩放。
