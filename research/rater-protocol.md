## 0. 三件仪器与关系（防混用）

| 仪器 | 回答什么 | 用途 |
| --- | --- | --- |
| **A. 缺陷普查** | 这份产物里到底有哪些缺陷（四维全量清点） | 检出率的分母 + 与参与者记录比对 |
| **B. 功能判据** | 任务卡判据逐条过没过（二值） | 产出质量指标之一 |
| **C. 八维样式分** | 整体样式质量（每维 0-2） | 产出质量指标之二（次要，与普查有概念重叠，如实声明） |

**顺序固定**：先 A 后 B/C（B、C 的判断会受普查发现影响，属预期；不得反向——先给印象分再找缺陷）。

## 1. 评级环境（统一，写入每份评分表头部）

- 产物本地运行（runs/ 内含启动说明）；Chrome 版本钉死（P3 冻结时记录）；视口：桌面 1440×900 + 移动 390×844 模拟；系统"减少动效"开关可切换。
- **盲法**：产物以随机码重命名，条件标签与参与者身份剥离；评级顺序随机。
- **诚实声明（写入论文）**：rater-1（用户）兼任会话主持人，无法完全盲；rater-2 全盲且未出席任何会话——rater-2 为主要盲评者，κ 以两人一致为准。

## 2. 仪器 A：缺陷普查手册

### 2.1 四维缺陷类型表（每个缺陷恰好归一类——按类型表归属，不按主观）

| 维度 | 码 | 缺陷类型 | 操作性定义 | 检查法 |
| --- | --- | --- | --- | --- |
| 功能 F | F1 | 不可用控制 | 按钮/链接无效果或效果错误 | 任务卡主链路逐一点击 |
|  | F2 | 数据/状态错误 | 显示与任务卡数据规则不符；过滤/排序/计数错 | 对照任务卡数据规则 |
|  | F3 | 构建/运行错误 | console 报错阻断、白屏、崩溃 | console + 构建产物运行 |
|  | F4 | 功能缺失 | 任务卡必做清单项未实现 | 对照判据清单 |
| 视觉 V | V1 | 对比度不足 | 正文 <4.5:1、大字 <3:1（WCAG AA） | **对比度测量脚本实测，禁止目测** |
|  | V2 | 字阶/层级缺失 | 无字号层级；标题与正文同级 | 截图留证 |
|  | V3 | 间距/对齐混乱 | 同类元素间距不一致、错位 | 截图留证 |
|  | V4 | 风格不一致 | 色彩杂乱、组件风格不统一 | 截图留证 |
|  | V5 | 响应式破损 | 固定宽度溢出、移动端布局崩 | 双视口截图 |
| 交互 I | I1 | 键盘不可达 | Tab 到不了交互元素 / 焦点顺序错乱 | 纯键盘走完整链路 |
|  | I2 | 焦点指示缺失 | 聚焦无可见焦点样式 | 键盘走查观察 |
|  | I3 | 状态反馈缺失 | 加载/提交/错误无任何反馈 | 主动触发各状态 |
|  | I4 | 动效违规 | hover/press 超 150ms 规格、`transition: all`、级联超 480ms | 代码检查+实测 |
|  | I5 | 边界行为缺陷 | 长文本溢出、空态未处理、中断异常 | 构造边界输入 |
| 无障碍 A | A1 | 语义/标签缺失 | 表单无 label、图片无 alt、空链接/按钮 | DOM 检查 |
|  | A2 | 颜色唯一传达 | 仅用颜色区分状态，无文字/图形冗余 | 关灰度截图复查 |
|  | A3 | 指针独占路径 | hover 才出现的功能无键盘/触达路径 | 键盘+触屏模拟 |
|  | A4 | 动效偏好未尊重 | `prefers-reduced-motion` 未降级大动画 | 系统开关切换复测 |

**归类边界**（最易混的三处）：对比度永远归 V1 不归 A；reduced-motion 未降级归 A4 不归 I4；"点了没反应"归 F1，"Tab 到不了"归 I1。

### 2.2 计数单位（防分母注水）

- 一个缺陷 =（组件模式，类型码）。同一组件模式的多个实例（如列表卡重复出现）计 **1 个**，另记"影响实例数"。
- 同一元素多种类型分别计（如同一个按钮既 F1 又 A1 → 两条）。
- 修而复发、多视口同缺陷 → 计 1，备注视口。

### 2.3 检查流程（每份产物约 40 分钟，顺序固定）

```text
① 按 runbook 启动（5'）→ ② console/构建错误 F3（2'）→ ③ 任务卡主链路走查 F1/F2/F4（10'）
→ ④ 桌面+移动截图组 V2/V3/V4/V5（8'）→ ⑤ 对比度脚本全量实测 V1（5'）
→ ⑥ 纯键盘全旅程 I1/I2（5'）→ ⑦ 状态探针 I3/I5（3'）→ ⑧ reduced-motion 切换复测 A4（2'）
→ ⑨ 语义扫描 A1/A2/A3（5'）→ ⑩ 汇总入普查表
```

### 2.4 普查表格式（每产物一份，JSONL）

```json
{"artifactId":"盲码","defectId":"D07","dim":"V","type":"V1",
 "pattern":"次级操作按钮","instances":4,
 "evidence":"contrast.txt#L12: #6a7076 on #fff = 3.2:1",
 "severity":"P1","notes":""}
```

严重度 P0/P1/P2 仅作参考属性（P0=阻断主链路），检出率计算**不按严重度加权**（预注册未定义加权，防止事后发明）。

## 3. 仪器 B：功能判据（二值）

- 每条判据按任务卡上的操作性检查执行，记 pass/fail。
- **"带缺陷可用"判 fail**：若该判据对应链路上存在普查 F 维缺陷 → fail；通过率 = passed / 总判据数。
- 判据与普查 F 项的对应关系在任务卡定稿（P2-1）时一并写死。

## 4. 仪器 C：八维样式分（每维 0-2，总分 = 100 × Σ/16）

| 维度 | 2 分锚点 | 0 分锚点 |
| --- | --- | --- |
| 布局节奏 | 分组/留白/栅格一致，主次分明 | 无分组、均匀堆砌 |
| 排版 | 有字阶系统，字重/行高有意图 | 单一字号，无层级 |
| 对比度实测 | 全部文本对过 AA 且附测量值 | 存在不过 AA 的文本对 |
| 状态覆盖 | loading/error/empty/disabled 全备 | 仅正常态 |
| 动效合规 | 有目的、参数合规、可降级 | 无动效或滥用（违规动画） |
| 可供性 | 可点元素有明确可供性暗示 | 纯文字当按钮、假控件 |
| 鲁棒性 | 边界输入/窄屏不破 | 长文本溢出、布局崩 |
| 一致性 | 组件/间距/色彩成体系 | 各处一套 |

1 分 = 介于两者之间（每维手册配 1 分锚例，试评后补充冻结）。

## 5. 检出率匹配规则（普查 × 参与者记录）

1. 共识普查：两评分者独立普查 → κ → 分歧讨论合并为**共识缺陷清单**（未决项 ≤5% 时用户终裁，计入如实报告）。
2. 匹配：参与者验收记录（C0=其自述报告与修复；C1=门 3 决策与问题清单确认）与共识清单比对——同模式+同类型（或描述明确对应）记"检出"。
3. 匹配执行：一名评分者全量匹配 + 另一名 20% 抽检；抽检不一致率 >10% 则全量双匹配。
4. 检出率 = 检出数 / 共识清单总数（分维度、分条件计算）。

## 6. 一致性规程与培训

- **试评校准（P3-4 干跑产物 ×2）**：培训一次（约 2 小时：手册走读+2 份独立试评+κ 试算）；κ ≥ 0.6 方进正式评分；不足则修手册锚点再训（最多 2 轮，仍不足触发预注册 §8 降级规则）。
- 正式评分 κ 报告：普查（总体+分维度）、样式分（加权 κ 或 ICC，N=20 报告）、功能判据（一致率+κ）。
- **盲拆封时点**：全部评分完成、κ 计算完、共识清单冻结后，才把盲码与条件对照表交分析（P5-3）——评分者全程不见条件。

## 7. 时间预算

普查 40' + 判据/样式 15' ≈ 55'/产物 → 每评分者约 18-19 小时（20 产物），分布在周 9-11，可行。

## 8. 边界与非目标

- 本协议不评判参与者行为对错，只清点产物缺陷与比对记录。
- 严重度仅参考属性；检出率不加权。
- 协议自身变更须记修订版本；试评后只允许补充锚例，不得改类型表结构。
