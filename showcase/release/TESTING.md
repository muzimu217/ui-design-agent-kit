# 公开测试

欢迎测试 UI Design Agent Kit 工作流的展示与成果案例。当前发布标识可在网站页脚查看。

## 两种不同测试

1. **成果体验**：所有访客都能打开公开 demo，检查界面是否可理解、操作是否可靠、手机是否可用。
2. **工作流执行**：仅面向已获源码或技能访问授权的测试者，检查需求、参考选择、原型确认、
   实现和验收是否按约定执行。没有执行工作流时，请不要把 demo 体验写成工作流测试结果。

## 首轮任务

- 库存运营台：搜索一种商品，切换库存筛选并排序，打开详情，使用 Escape 关闭，再在手机尺寸重复。
  数据是演示数据，不连接真实库存；动作提示不代表产生真实业务操作。
- 积木小工坊：选择砖型和颜色，放置三块积木，移动或复制其中一块，撤销重做，保存后刷新检查。
  存档只在当前浏览器，隐私模式或浏览器清理可能删除本机数据。
- 展示站：切换工作流阶段，按类型筛选案例，查看原图，进入 demo 并返回成果库。

不要求花固定时长，也不要求为了完成测试提交真实信息。发现一个可复现问题就有价值。

## 反馈

通过 [反馈表单](https://github.com/muzimu217/ui-design-agent-showcase/issues/new/choose)提交，需要 GitHub 账号。
填写页面网址、页脚版本、浏览器与设备、最短复现步骤、预期与实际结果。
截图或录屏是可选证据；请先遮盖个人信息。

**反馈会公开。** 不要粘贴令牌、密码、客户数据、内部提示词、私有代码或完整聊天记录。
我们没有开启后台录屏或行为跟踪；页面也不会自动上传作品。

## 后续处理

维护者先确认问题属于成果实现、工具/环境、设计契约还是工作流决策，再安排复现、修复和复验。
仅有一个页面缺陷时，不会直接改写整个 Agent 规则。下一产品建议会按它能验证的能力和可测目标筛选，
不会用 demo 数量替代工作流质量。

这里是公开邀请，不代表已经招募到测试者、收到了反馈或完成了用户研究。没有奖励或付费承诺。
