## 二、浏览器验证（审核官亲自执行）

### QG5 / A2 · 首屏见读数 — ✅ 通过

在 375×812 与 1440×900 两种视口实测，首屏不滚动即可见**完整读数**：

```
06:24   潮位 2.87 米   退潮中
```

读数为大号数字（移动端 clamp 到 40px+），黄色「演示数据」徽章在位。两种视口均无横向溢出。

### QG9 / A4 · 键盘走查 — ✅ 通过

实测时间轴控件：

```
input[type=range]  可聚焦 ✓
computed: display:block  visibility:visible  opacity:0   ← B3 正确实现
在布局中: 1030×320                                        ← 未脱离布局
aria-label: "潮汐时间轴，方向键调整，每步 10 分钟"
按 ArrowRight: value 39 → 40，读数 06:24 → 06:25          ← 键盘可操作
```

**关键点**：用 `opacity:0` 而非 `display:none`，控件保留在布局中且可聚焦——B3 要求正确落实。

### QG14 · 焦点环 — ✅ 通过

场景卡文案实测为**基于读数的判断**，不是潮汐科普：
